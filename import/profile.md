# 固定記事案

## このnoteで、これから発信すること

こんにちは。大学病院で理学療法士として働いている夏目漱右です。

これまで、このnoteでは姿勢、認知症、組織、未来のリハビリテーションなど、関心のあるテーマを幅広く書いてきました。過去の記事は、当時の学びと試行錯誤の記録として、そのまま残します。

これからは、発信の中心を次の4つに絞ります。

1. 高度急性期における臨床判断と臨床思考
2. 若手リハ職へ判断根拠を伝える臨床教育
3. 病院という複雑な組織を動かす仕組み
4. 医療職による生成AIの安全で実践的な活用

AIを使えば、文章や資料を短時間で作れるようになりました。しかし、医療では「速く作れる」だけでは不十分です。患者さんの情報を守ること、出典を確認すること、AIの誤りを見抜くこと、最後は専門職が責任を持って判断することが欠かせません。

このnoteでは、AIにすべてを任せる方法ではなく、AIを下書きや整理に使い、人が確認して仕上げる方法を扱います。同時に、臨床、教育、管理を別々の仕事として切り離さず、「なぜ今それをするのか」「相手の反応が違ったら何を変えるのか」という判断の組み立て方を言葉にします。私自身が実践しながら、うまくいった点だけでなく、迷った点や使わない方がよい場面も共有します。

過去の記事と少し雰囲気が変わりますが、根底にある「リハビリテーションの未来を考える」という関心は変わりません。医療職としてAIとどう付き合うかを、一緒に考えられる場所にしていきます。

本noteの内容は教育・情報提供を目的とし、個別の診断や治療を代替するものではありません。臨床への適用は、所属施設の規定と最新の一次情報を確認したうえで、専門職として判断してください。
