## 控え

順番は決めていないが、書く候補。

- 病院を複雑適応系として見る
- AIが作った医学記事の誤りを見抜くチェックリスト

## 運用メモ

- 1〜7本目は無料で出し、どの悩みに反応があるかを見る
- 8本目でチェックリストを無料公開し、保存需要を確かめる
- 9本目以降、反応が良かった内容を有料化する(980〜1,980円を想定)
- 10本出したら `note-publication-log.md` の実績を見て、4本柱のどれを主軸にするか決める
- 固定記事(No.0)を最初に公開し、過去記事を残したまま方向転換を説明する

## 原稿を取り込むとき

別ディレクトリの完成原稿を `posts/` へ移す手順。

1. `posts/_template.md` の front matter に合わせて `title` / `account` / `tags` / `publish` を付ける
2. すでに note に下書きがあるなら `note_url` も書く(以後 `update` で上書きできる)
3. `python scripts/note_lint.py posts/<ファイル>.md` で公開前チェックを通す
4. このファイルの「原稿」列と「状態」を更新する
