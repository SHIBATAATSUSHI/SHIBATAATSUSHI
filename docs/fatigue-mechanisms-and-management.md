# 倦怠感 — 分子生物学から対応策まで

> 作成日: 2026-08-09 / 医学的助言ではなく文献の整理。個別の判断は医療者と。

## 0. この文書の立場

「倦怠感」は**症状名ではなく、少なくとも8つの異なる状態を包む袋**である。仮説どおり、この語には相当な部分がマスクされている。
以下では (1) まず袋を開けて中身を分解し、(2) 分子・生理・認知の各レイヤーで何が言われているかを整理し、(3) 「動くべきか休むべきか」の分岐条件と対応策に落とす。

読者(=依頼者)が提示した仮説 — 体温上昇の代謝コスト、不動による血流低下、体力による境界の移動、ワーキングメモリ飽和、脳ネットワークの非効率化 — は**いずれも文献上の裏付けがある**。ただし効き方の大きさと成立条件が違う。それを本文で定量的に区別する。

---

## 1. 「倦怠感」の分解

### 1.1 まず用語を分ける

疲労研究では `fatigue`(自覚症状)と `fatigability`(疲労性=負荷で低下する性質)を分ける枠組みが標準化されている(Enoka & Duchateau)。fatigability はさらに2つに割れる。

| 概念 | 中身 | 測り方 |
|---|---|---|
| **Perceived fatigability**(自覚的疲労性) | 恒常性維持に関わる感覚の変化。心理状態と生理的余力に依存 | RPE、自己申告スケール |
| **Performance fatigability**(遂行的疲労性) | 客観的パフォーマンスの経時的低下。収縮機能と筋活性化に依存 | 最大随意収縮力、反応時間、タスク成績 |

重要なのは**この2つが乖離しうる**こと。「きついのに出力は落ちていない」「出力は落ちているのに本人は自覚していない」の両方が起こる。倦怠感の訴えを一元的に扱うと、この乖離が見えなくなる。

### 1.2 袋の中身(8軸)

臨床的には次の軸を独立に評価すべきで、どれも日本語では「だるい」に圧縮される。

| # | 軸 | 中核の異常 | 見分けるサイン |
|---|---|---|---|
| 1 | **眠気**(sleepiness) | 睡眠圧・睡眠の質 | 座ると寝落ちる、仮眠で回復 |
| 2 | **疲労感**(fatigue) | 労作なしでも持続する消耗感 | 休んでも取れない、仮眠で回復しない |
| 3 | **運動不耐**(exercise intolerance) | 循環・代謝・ミトコンドリア | 軽い労作で動悸・息切れ・脱力 |
| 4 | **筋力低下**(weakness) | 神経筋 | 力が入らない(だるさとは別) |
| 5 | **認知的疲労**(cognitive fatigue) | 前頭前野・制御資源 | 頭が回らない、判断が雑になる |
| 6 | **アパシー**(意欲低下) | 線条体・前部帯状回のドパミン系 | やる気の起点が立たない、苦痛感は薄い |
| 7 | **抑うつ・アンヘドニア** | 気分・報酬系 | 興味喪失、自責、日内変動 |
| 8 | **起立不耐** | 自律神経・前負荷 | 立位・座位維持で悪化、臥位で軽快 |

臨床上いちばん実務的な追加軸が **PEM(労作後倦怠感, post-exertional malaise)** の有無。PEMは「活動後に数時間〜数日**遅れて**出現し、活動量に不釣り合いで、回復に長時間を要する症状増悪」と定義される。この有無が後述する「動く/休む」の最大の分岐点になる。

## 2. 分子生物学レイヤー

### 2.1 筋内で起きること(末梢性疲労)

Allen–Lamb–Westerblad 系の細胞レベル研究が骨格。要点:

- **無機リン酸 (Pi) の蓄積**が主犯格。PiがSR(筋小胞体)内に入り Ca²⁺ と沈殿することで**放出可能なCa²⁺が減る**。ラットでは張力低下は酸性化(H⁺)よりもPi濃度と一貫して相関する。かつて主役とされた乳酸アシドーシスは、現在は主因から降格している。
- **ATP低下 と Mg²⁺上昇** による SR Ca²⁺ チャネル(RyR1)開口効率の低下。
- **RyR1 の酸化・過リン酸化による Ca²⁺ リーク**。運動でRyR1はPKA過リン酸化され、加齢や慢性ストレスでは酸化的修飾によって慢性的な漏出が生じ、筋力低下・易疲労につながる。ROSとリークの**フィードフォワード・ループ**を形成する。
- グリコーゲン枯渇、興奮収縮連関の障害、神経筋伝達。

要するに末梢性疲労は「エネルギーが尽きる」より **「Ca²⁺ハンドリングが壊れる」** 現象として理解されている。

### 2.2 ミトコンドリアと細胞エネルギー代謝

慢性倦怠感側でいま最も動いている領域。

- **WASF3**(PNAS 2023, ME/CFS): 患者の骨格筋生検で WASF3 タンパクの増加と ER ストレスの異常活性化。WASF3はアクチン重合を促してグリコリシスを駆動し、ミトコンドリア呼吸を抑制する。マウスでER ストレス誘導 → 複合体IV低下、ER ストレス阻害薬で WASF3 を下げると患者細胞のミトコンドリア機能が改善した。「運動不耐の分子的説明候補」として重要。
- **long COVID のミトコンドリア異常**: OXPHOS 低下、構造変化、脂肪酸酸化障害の報告が集積。ME/CFS の所見と重なるため共通経路仮説が唱えられている。
- **PDH(ピルビン酸脱水素酵素)阻害仮説**(Fluge & Mella ら): 解糖からTCAへの入り口が絞られ、アミノ酸の異化に依存する代謝プロファイル。
- **NAD⁺/レドックス低下**。
- **イタコン酸シャント仮説**: 活性化マクロファージの代謝中間体イタコン酸がSDH(複合体II)を阻害し慢性的な代謝停滞を作る、というME/CFS向けの提唱がある。**理論段階で、ヒトでの直接検証はまだ弱い**ため、確立事実として扱わないこと。

### 2.3 免疫 → 脳(sickness behavior)

「感染すると寝込む」のは副作用ではなく**進化的にプログラムされた行動**であり、倦怠感研究の最も確実な部分。

- IL-1β、IL-6 の産生量が、発熱・倦怠感・疼痛・気分低下・集中困難と相関する(ヒト実験)。
- TNF と IL-6 が脳血管内皮を刺激 → **PGE₂** 産生 → 体温調節中枢と、GPCRを介した神経細胞への直接作用で、発熱・痛覚過敏・食欲低下・warmth-seekingを起こす。最近は島皮質でPGE₂が「病気であること」の統一表象を作るという報告も出ている。
- **迷走神経求心路**が末梢サイトカイン→中枢の主要ルート。迷走神経切断でLPS誘導 sickness behavior は消える。
- **I型IFN・IFN-γ は筋細胞に直接作用して疲労を誘導**する経路も報告されている。

つまり倦怠感は「エネルギー不足の受動的結果」ではなく、**免疫系が行動を能動的に書き換えている出力**でもある。これは「動くべきか」を考えるときの前提を変える。

### 2.4 トリプトファン → キヌレニン → ドパミン低下

炎症と「やる気が出ない」をつなぐ最も追跡されている分子経路。

1. IFN-γ 等が **IDO1** を誘導 → トリプトファンがキヌレニン経路へ流れる。
2. セロトニン原料が減り、キヌレニン代謝物(キノリン酸など)が増える。
3. 同時に炎症による酸化ストレスが **BH4(テトラヒドロビオプテリン)** を消耗させ、チロシン水酸化酵素の補酵素が枯れて**カテコラミン合成が落ちる**。
4. 結果として**線条体ドパミンの低下** → 努力に対する報酬の割引率が上がる → アンヘドニア、易疲労、精神運動制止(Felger & Miller の "inflammatory malaise")。

ME/CFSではキヌレニン産生量と症状重症度の相関が報告されている。がん関連疲労でも炎症性トリプトファン異化が疲労・貧血・抑うつと関連する。
「炎症 → 意欲低下」は、心理的な弱さではなく**神経化学的なコスト計算の変更**として説明されている点が重要。

### 2.5 睡眠圧: アデノシン

覚醒の持続で前脳基底部にアデノシンが蓄積し、**A1受容体**を介して覚醒促進ニューロンを抑制する。断眠でA1受容体密度自体も上がる(ヒトPET)。カフェインはA1/A2A拮抗で「眠気の知覚」を消すが、**アデノシン蓄積そのものは進行し続ける**。カフェインが倦怠感の借金を返済しない理由がここにある。

### 2.6 認知的疲労の神経代謝

Wiehler ら(Current Biology 2022, n=39, 6時間の課題)は MRS で、**高負荷の認知作業後に外側前頭前野(lPFC)のグルタミン酸濃度と拡散が上昇**し、視覚野(対照領域)では上がらないことを示した。解釈は「資源の枯渇」ではなく **「代謝産物の蓄積によって当該領域の動作が非効率になる」**。この状態で経済的意思決定は衝動的側(即時報酬・低努力)に傾く。

これは「脳の部位ごとの効率が落ちる」という仮説にほぼ直接対応する所見である。

### 2.7 血管・内皮・微小循環

内皮機能障害、微小循環の灌流低下、long COVID での微小血栓仮説などが議論されている。ただしこの領域は**再現性の議論が続いており**、確定所見として扱うべきではない。

## 3. 生理レイヤー — 提示された仮説の検証

### 3.1 仮説A「体温上昇 → 呼吸数増加・代謝過剰で身体の可用性が食われる」→ **成立する。定量も出せる**

**(a) 発熱の代謝コスト**
体温1℃上昇あたり代謝率は **約8〜13%増加**(古典的研究で約13%、小児TPN研究で11.3%/℃、教科書的には10〜12.5%)。これに伴い酸素消費・心拍出量・換気需要・栄養需要がすべて上がる。40℃の発熱なら安静時代謝は約1.3〜1.4倍で、**寝ていても軽い運動相当の代謝を回している**ことになる。

**(b) 呼吸仕事そのもののコスト**
換気の酸素コストは安静時には全VO₂の数%だが、最大運動時には **VO₂max の 10 ± 0.7%**、呼吸筋の予備を使い切る被験者では **13〜15%** に達する。さらに「重度→最大運動」の移行域では、**換気増加分のO₂コストが全身VO₂増加分の 39 ± 10%** を占める。

**(c) 呼吸筋メタボリフレックスによる血流の"横取り"**
呼吸筋の仕事が増えると交感神経性血管収縮を介して**四肢筋への血流が奪われる**。呼吸仕事と脚のO₂取り込みは逆相関する。心不全患者ではこの現象がより顕著。

**(d) 高体温そのものによる中枢性疲労**
40℃環境・60%VO₂max の運動では、深部体温 40.0℃到達時に **随意的活性化率が 82% → 54% に低下**した。一方で筋の総発揮力は保たれていた。つまり**筋は動けるのに中枢が指令を出さなくなる**。局所筋温ではなく**深部体温**が決定因子であることも示されている。

→ **結論**: 「発熱時のだるさ」は少なくとも4経路の合算 — 代謝需要の底上げ、呼吸仕事の増大、呼吸筋への血流再配分、深部体温による中枢性抑制 — に加えて、2.3節のサイトカイン→PGE₂→行動変容が乗る。仮説は正しく、しかも想定より多層である。

### 3.2 仮説B「不動 → 血流低下」→ **成立する。ただし主役は"血流"より"血漿量と心臓の縮小"**

ベッドレスト研究(Dallas系列など)の代表的な変化:

| 指標 | 変化 |
|---|---|
| 血漿量 | **−17%** |
| 肺動脈楔入圧(前負荷) | −18% |
| 1回拍出量 | −12% |
| 左室拡張末期容積 | −16% |
| 最高酸素摂取量 | **−33%** |
| 起立耐性 | −24% |

期間・プロトコルにより幅はあるが、順序としては **血漿量減少(数日)→ 心筋の萎縮・スティフネス変化(1〜2週)→ 骨格筋・毛細血管・インスリン感受性(週単位)** と進む。

重要な機序として、頭低位ベッドレストは**急性の脱水では起きない心室リモデリング**を引き起こす。心臓が小さく伸展性の低い状態になり、Starling曲線が急峻化するため、起立負荷で1回拍出量がより大きく落ちる。**「単に水が減った」のではなく、ポンプの形状が変わる**。

対策として、運動単独より **運動 + 容量負荷(補液)の併用**のほうが起立耐性の低下を防げたという結果がある。

→ 「動かないと血が巡らなくなるのでは」という直感は正しい。ただし介入設計上は「歩かせる」より **「臥位/座位の有酸素運動 + 塩分・水分で血漿量を戻す」** ほうが理にかなう場面がある(§6.3)。

### 3.3 起立不耐・POTS

上記のデコンディショニングと自律神経異常が重なると、立位で脳血流が保てず「立っているだけで消耗する」状態になる。デスクワークですら座位保持の負荷になるため、**「何もしていないのに疲れる」の正体がこれである場合がある**。

### 3.4 睡眠のレイヤー

倦怠感の鑑別で最も見落とされやすいのが睡眠。閉塞性睡眠時無呼吸、不眠、概日リズム後退、周期性四肢運動。「眠気」と「疲労感」は独立の軸(§1.2)で、OSAは両方を出しうる。

## 4. 認知・脳ネットワークのレイヤー

### 4.1 認知的疲労は「資源枯渇」ではなく「コスト計算のシフト」

現行の主流モデルは、疲労を**努力の主観的コストが上がる現象**として定式化する。

Müller & Apps(Nature Communications 2021)の計算モデルでは、疲労は**2つの潜在状態**に分かれる:

- **回復可能な (recoverable) 成分** — 休息で戻る
- **回復不能な (unrecoverable) 成分** — 労作量に応じて蓄積し、短い休息では戻らない

両者とも「報酬のために努力を払う意思」を下げる。神経的には、**運動野/前運動野の状態信号が島皮質(anterior insula)の努力価値計算に入力**し、これから払う身体的努力の主観的価値を押し上げる。

実務的含意は大きい。**「休めば戻る疲労」と「休んでも戻らない疲労」は別物として蓄積している**ので、日次の回復だけを見ていると後者が静かに積み上がる。

### 4.2 ワーキングメモリ容量は効くのか → **効く。ただし"容量"より"負荷と自動化"**

- 警戒課題(vigilance)の成績低下は、**同時のWM負荷で悪化**する。空間性・言語性のどちらの負荷でも起こることから、共通の実行系資源を食い合っていると解釈される。
- 決定的なのは、この結果が **「退屈・低負荷だから注意が落ちる」説ではなく「認知資源需要が高いから落ちる」説を支持する**こと。つまり**ワーキングメモリが埋まる → 疲れる**という直感は支持される。
- 主観的疲労と客観的パフォーマンス低下は**乖離する**。ある研究では、**課題回避行動と相関したのは客観的疲労であって主観的疲労ではなかった**。自己申告だけで疲労を管理すると外す。

### 4.3 IQは関係あるか → **直接の証拠は弱い。説明力があるのは別の変数**

正直に書くと、「IQが高い人は認知的に疲れにくい」を直接支持する強い証拠は見当たらない。関連しそうな変数は以下:

| 変数 | 疲労への効き方 | 確からしさ |
|---|---|---|
| **WM容量 / 流動性知能** | 同じ課題の相対負荷を下げる(容量に対する占有率が下がる) | 中程度。ただし「疲れにくさ」の直接測定は少ない |
| **課題の自動化・熟達度** | 実行系の関与自体を減らす。おそらく**最大の効き** | 高い(スキル獲得研究一般) |
| **Need for Cognition / 自己制御** | 高いほど努力の割引(effort discounting)が小さく、認知的要求を回避しにくい。努力回避による"安堵"も小さい | 中程度、再現あり |
| **Cognitive reserve** | 負荷・損傷・加齢に対する耐性の個人差 | 概念として確立、疲労特化の実証はこれから |

したがって「認知的許容量」は **WM容量(ハード) × 自動化度(ソフト) × 動機づけ特性(値付け)** の積として考えるほうが実態に近い。IQを固定パラメータとして扱うより、**自動化と外部化で実効負荷を下げる**ほうが介入可能性が高い。

### 4.4 脳ネットワーク・可塑性 → **「非効率になっている」に対応する所見はある**

- **視床-線条体-皮質ループ**が中枢性疲労の中核として繰り返し同定される。MSでは、**皮質-皮質間および皮質下-皮質下間の結合は強い一方、皮質-皮質下間の結合が弱い**という所見があり、「制御ループの断線」として解釈される。
- 同様の striato-thalamo-cortical / 前頭ネットワークの統合性低下が、外傷性脳損傷後や高齢者の認知的疲労とも関連する。
- TBI後の病的疲労では、**時間経過とともに前頭前野ネットワークが分離(segregation)していく**パターンが報告される。「使うほど協調が崩れる」像。
- メタ解析レベルでも、精神的疲労の機能的相関としてこのループ群が横断的に浮かぶ。

**白質・ミエリン側**も無視できない。軽症呼吸器COVIDのモデルで、**CCL11 を介した白質選択的ミクログリア反応 → オリゴデンドロサイト前駆細胞とミエリンの喪失 → 伝導速度と軸索代謝の障害**という経路が示され、化学療法後の "chemo-fog" と共通機序として議論されている。持続的認知症状のあるヒトでも CCL11 上昇が確認された。海馬では神経新生の抑制も観察されている。

→ 「脳部位の可塑性やネットワークの動きが悪い/非効率」という仮説は、**(a) 代謝産物蓄積による局所効率低下(§2.6)、(b) ループの結合異常、(c) ミエリン・伝導の障害** という3つの異なる水準で裏付けがある。ただしこれらは主に**病態群(MS, TBI, long COVID)**での所見で、健常者の日常的疲労にそのまま外挿はできない。

### 4.5 メタ認知説 — 倦怠感は「身体を制御できない」という推論の結果

Stephan らの **allostatic self-efficacy 理論**(2016)は、階層ベイズ的な内受容モデルから倦怠感を導出する。

1. 内受容(interoception)の予測誤差が慢性的に高い状態 = **dyshomeostasis**(身体信号についての驚きが慢性的に高い)。
2. これをメタ認知層が監視し、「自分の脳は身体状態を制御できているか」という信念(**allostatic self-efficacy**)を更新する。
3. この信念が低下した結果の一次反応が **倦怠感**、さらに慢性化した結果が **抑うつ**、という順序で説明する。

この理論の実務的価値は、**「炎症も貧血も検査で出ないのに強い倦怠感がある」状態に、心因論に逃げずに機序を与える**点にある。また「予測可能性を回復させる介入(ペーシング、記録、予測誤差の縮小)」が理にかなう理由も説明する。

## 5. 代表的な病態と、いま言われていること

### 5.1 感染後疲労: ME/CFS と long COVID

現在この領域は最も研究が集中し、同時に**最も論争的**。

**筋レベルの直接証拠(Appelman et al., Nature Communications 2024)**
long COVID 患者に対し 2日間CPET で PEM を誘発し、前後で筋生検を実施。PEM誘発後に:
- ミトコンドリア指標の即時かつ重度の低下
- 萎縮線維の増加
- 免疫細胞の広範な浸潤
- **骨格筋内のアミロイド含有沈着物の増加**

「気のせい」でも「単なるデコンディショニング」でもない**組織学的変化**が、労作閾値を超えた後に起きることを示した点で重要。この論文は運動療法の是非をめぐって Nature Communications 誌上で応酬(letter と reply)になっている。

**NIH 深層表現型研究(Walitt et al., Nature Communications 2024)と "effort preference" 論争**
感染後ME/CFS患者を8年かけて多面的に評価した研究。EEfRT課題で、同じ報酬条件下で患者は健常者より難易度の高い課題を選ばなかったとし、これを **"effort preference"(どれだけ努力したいか)** の差、「できると思っていることと身体が実行することのミスマッチ」と解釈した。
この解釈には強い批判がある — **同じ課題でも患者にとっての実コストは健常者より高いのに、それを補正していない**という指摘。EEfRT の妥当性そのものも議論の対象。**この研究を引用するときは、所見と解釈を分けて扱う必要がある。**

**治療試験の現状(2026年時点)**
- RECOVER-CT は13治療の登録を2025年に完了、RECOVER-TLC がバリシチニブ、低用量ナルトレキソン(LDN)、セマグルチド、星状神経節ブロックなどを検証中。**結果は2026年末までに出そろう見込み**で、現時点では確立治療と呼べるものはない。
- LDN はメタ解析で疼痛に大きめ・睡眠に中等度の効果量が報告される一方、疲労への効果は確定していない。NK細胞の TRPM3 機能回復という機序的知見はある。
- 英国の三剤併用試験は否定的結果。

### 5.2 がん関連疲労(CRF) — エビデンスが最も整っている領域

- **非薬物が第一選択**。57件のRCTのメタ解析で**運動と心理的介入がともに CRF を減らし、両者に有意差なし**。ヨガ、マインドフルネス、心理社会的介入にも効果。
- **メチルフェニデート**: 5試験426名で SMD −0.28、別のメタレビューで −0.48(95%CI −0.75〜−0.21)。**ASCOは条件付きで日常的使用に反対、NCCNは非薬物が不十分な場合の選択肢として残す**。2026年のメタ解析では効果が明確になるのは**5週以降**。
- **明るい光療法**: 疲労に対する効果量は Hedge's g ≈ 0.47 で、睡眠指標への効果より大きいという報告。

### 5.3 多発性硬化症(MS)の疲労 — 薬は効かなかった

**TRIUMPHANT-MS**(Lancet Neurology 2021, n=141, 4期クロスオーバー、二重盲検): **アマンタジン、モダフィニル、メチルフェニデートのいずれもプラセボに優越せず、有害事象はむしろ多かった**。長年の標準的処方を否定した重要試験。
→ MS疲労では**運動療法・エネルギーマネジメント教育・CBTなどの非薬物**に重心が移っている。

### 5.4 一次診療で見るべきもの

- 一般人口で高頻度。プライマリケア受診者の**最大15%**が疲労を訴える。
- 原因の内訳(系統的レビュー): **うつ 18.5%、重篤な身体疾患 4.3%、貧血 2.8%、悪性腫瘍 0.6%**。つまり**多数派は単一の器質的原因では説明されない**。
- **検査が方針を変えるのは約5%**。初回が正常なら、闇雲な再検査は推奨されない。レッドフラグ(体重減少、発熱持続、リンパ節腫脹、夜間症状、局所神経症状)がなければ、**丁寧な問診 + 限定的な検査 + 経過観察**が合理的とされる。
- **鉄**: 非貧血の鉄欠乏に対する鉄補充は、**フェリチン ≤15 ng/mL の高度枯渇群でのみ**疲労改善が示された(Blood 2011)。一方、フェリチン ≤50 µg/L の献血者405名を対象とした静注鉄のRCT(2020)では、ヘモグロビン・フェリチンは上がったが**疲労と全般的健康感は改善しなかった**。「フェリチンが低め=鉄を入れれば元気になる」は成り立たない。

## 6. 「動いた方がいい」と「休んだ方がいい」の境界

依頼者の中心的な問いに直接答える。**単一の答えはなく、分岐条件がある。**

### 6.1 最大の分岐は PEM の有無

```
倦怠感がある
├─ PEM あり(活動の12〜72時間後に不釣り合いな増悪、回復に日単位)
│   → 【休息側・ペーシング】漸増固定の運動療法は禁忌
│      NICE NG206(2021)は GET を推奨から削除。「症状を押して課題を完遂しない」
│      エネルギー封筒の内側に留まることを原則とする
│
├─ PEM なし + デコンディショニング型(不動・入院後・術後・加齢)
│   → 【運動側】漸進的運動が最も有効な単一介入
│      §3.2 の変化は運動で可逆
│
├─ PEM なし + 起立不耐が主(立位・座位で悪化、臥位で軽快)
│   → 【臥位から始める運動】+ 容量負荷(§6.3)
│
├─ 急性感染・発熱中
│   → 【休息】§3.1 の代謝コストが乗っており、心筋炎リスクもある
│      解熱後、症状が消えてから段階的に戻す
│
└─ 認知的疲労が主(§4)
    → 【負荷の再設計】休息だけでは回復不能成分が残る。§7.5 へ
```

**PEMの有無を最初に判定する**という順序が、この10年で最も大きく変わった実務上の点である。

### 6.2 体力(予備能)は境界をどう動かすか

「体力による影響はありそう」という直感は正しく、機序も明確:

- 同じ**絶対**負荷でも、VO₂max が高い人ほど**相対**負荷(%VO₂max, %心予備能)が低い。§3.1(c) の呼吸筋メタボリフレックスも、§2.1 の代謝産物蓄積も、**相対強度で決まる**。
- 血漿量・心室コンプライアンスが大きいほど、起立負荷や熱負荷に対する余裕が大きい。
- したがって**同じ「30分の散歩」が、ある人には回復刺激、別の人には閾値超え**になる。活動を分数や歩数で管理すると必ず失敗する。

**含意**: 活動量は絶対量ではなく **相対強度(心拍・RPE・会話可能性)** で規定すべき。

### 6.3 実務的な閾値の置き方

| 状況 | 目安 |
|---|---|
| **PEMのある人** | 心拍上限を設定(嫌気性閾値以下、簡易には「安静時心拍 + 15」や「(220−年齢)×0.55〜0.6」など個別化)。ウェアラブルでアラート。活動を短いブロックに刻み、**予定的に**休む(疲れてから休むのでは遅い) |
| **起立不耐** | **臥位・座位から開始**。Levine/CHOP プロトコルでは最初の1〜2ヶ月は**厳密に臥位・座位**(リカンベントバイク、ローイング、水泳)。トレッドミルや階段は使わない。3ヶ月で改善、6ヶ月まで漸増。塩分・水分・圧迫衣を併用 |
| **デコンディショニング** | 会話可能ペース(talk test)、Borg RPE 11〜13。週単位で漸増 |
| **共通の中止基準** | 翌日〜翌々日に持ち越す増悪が出たら、直前の負荷が閾値超え。**2〜3日の遅発を見るため、活動ログは最低3日窓で評価** |
| **暑熱下** | 深部体温が効くので(§3.1d)、環境温・湿度を独立変数として記録。冷却(プレクーリング、冷水摂取)は中枢性疲労を後ろにずらす |

## 7. 治療・リハビリ・対応策

### 7.1 まず可逆因子を潰す

- **薬剤レビュー**(β遮断薬、抗ヒスタミン薬、鎮静系、抗うつ薬、降圧薬)— 最も見落とされ、最も可逆
- 血算、フェリチン、TSH、HbA1c/血糖、腎肝機能、電解質、CRP、ビタミンB12、必要に応じてセリアック、睡眠時無呼吸のスクリーニング
- **うつ・不安の評価**(頻度が最も高いカテゴリ)
- **アルコール**、カフェインのタイミング(§2.5)

### 7.2 睡眠

- **CBT-I** が第一選択。不眠重症度と**疲労の両方に大きい効果**。睡眠効率 +8〜16%、入眠潜時 −30〜45分。ただし睡眠制限期に**一時的に疲労が増える**ことを事前に説明しないと脱落する。
- OSA の治療。
- **高照度光療法**: 疲労への効果量 g ≈ 0.47。朝の使用。がんサバイバーのRCTで疲労改善。

### 7.3 運動処方(§6の分岐に従う)

- デコンディショニング型・がん関連疲労: **運動が最良の単一介入**。有酸素 + レジスタンス。
- 起立不耐: 臥位開始の Levine/CHOP。
- PEM型: **漸増固定の運動プログラムは行わない**。安定してから、自覚に依存しない客観指標(心拍)で管理された範囲内の低強度活動に留める。

### 7.4 ペーシング / エネルギーマネジメント

作業療法士主導の**エネルギーマネジメント教育(EME)**は、MS・慢性疾患・long COVID で自己効力感、疲労の生活影響、QOLの改善が示されているマニュアル化された介入。中核は古典的な **3P**:

- **Pacing**(配分): 活動と休息を予定に組み込む。「疲れる前に休む」
- **Planning**(計画): 高負荷タスクを日内の余力ピークに配置、分散
- **Prioritizing**(優先): 捨てるものを先に決める

これは §4.5 の枠組みで見ると **「内受容の予測誤差を減らして allostatic self-efficacy を回復させる」介入**として理解できる。記録して予測可能にすること自体に効果がある。

### 7.5 認知的負荷のマネジメント

§4 の知見から直接導かれる実務策:

| 原理 | 施策 |
|---|---|
| WM占有を減らす(§4.2) | 外部化(書く、チェックリスト、記憶に頼らない)。**同時保持項目を減らす**設計 |
| 実効負荷は自動化度で決まる(§4.3) | 頻出タスクは手順を固定してテンプレ化・自動化。「毎回考える」を潰す |
| 代謝産物の蓄積(§2.6) | 長時間の連続制御作業を避ける。**同種の高制御タスクを6時間続けない**。異種タスクへの切替は蓄積部位を変える可能性がある |
| 回復不能成分がある(§4.1) | 日次の休息では戻らない蓄積があると前提し、**週・月単位の回復ブロック**を確保 |
| 主観と客観が乖離(§4.2) | 自己申告だけで判断しない。**成績指標(エラー率、所要時間、判断の質)**を併記して記録 |
| 疲労時は衝動側に傾く(§2.6) | 重要な意思決定・コミット・購買を**疲労時に置かない**ルール化 |

### 7.6 薬物療法の現状

| 対象 | 薬 | 現状 |
|---|---|---|
| MS疲労 | アマンタジン / モダフィニル / メチルフェニデート | **3剤ともプラセボ非優越、有害事象多い**(TRIUMPHANT-MS)。無差別使用は支持されない |
| がん関連疲労 | メチルフェニデート | 効果量 −0.28〜−0.48。ASCOは条件付き反対、NCCNは選択肢。効果発現は5週以降 |
| 非貧血の鉄欠乏 | 経口/静注鉄 | フェリチン ≤15 の高度枯渇でのみ疲労改善。≤50 では改善なし |
| long COVID / ME/CFS | LDN、ピリドスチグミン、その他 | **確立治療なし**。RECOVER-TLC 等の結果待ち(2026年末) |
| 起立不耐 / POTS | 塩分・水分負荷、圧迫衣、ミドドリン、β遮断薬少量など | 非薬物(容量負荷+臥位運動)が土台 |

**総括すると、倦怠感に対して確実に効く薬はほぼ存在しない。** 効果が確立しているのは、原因疾患の治療、睡眠の是正、条件を選んだ運動、エネルギーマネジメントである。

### 7.7 心理・行動

- **CBT** は ME/CFS では**補助的であって治癒的ではない**とNICEが明示。がん関連疲労では運動と同程度に有効。
- **マインドフルネス**: 神経疾患の疲労に対して g ≈ −0.37(中等度)、がんサバイバーの疲労と活力にも有意な改善。
- 病態説明そのもの(何が起きているかを理解すること)が予測誤差を下げるという理論的根拠がある(§4.5)。

## 8. 自己観察のためのログ設計

倦怠感は「一つの量」ではないので、単一スコアで追うと必ず情報が落ちる。最低限、次を分けて記録する。

| カテゴリ | 項目 | 理由 |
|---|---|---|
| 分解 | 眠気 / 消耗感 / 頭の回らなさ / 意欲 / 息切れ / 立位時の悪化 を**別々に**0-10 | §1.2 の8軸を潰さない |
| 客観 | 安静時心拍、HRV、睡眠時間・効率、歩数、起立時心拍上昇 | 主観と客観の乖離を検出(§4.2) |
| 負荷 | 身体的活動の**相対強度**(心拍/RPE)、認知的高制御作業の連続時間 | 絶対量では閾値が決まらない(§6.2) |
| 環境 | 気温・湿度、体温 | 深部体温が中枢性疲労の決定因子(§3.1d) |
| 遅発 | **翌日・翌々日**の症状 | PEM は12〜72時間遅れる(§6.3) |
| 成績 | エラー率、所要時間、決定の質 | performance fatigability を捉える(§1.1) |

分析は**3日窓のラグ相関**で見る。当日の相関だけを見ると PEM を見逃す。

## 9. 留意点(この分野を読むときの注意)

1. **論争が多い領域である**。特に ME/CFS・long COVID の運動療法、NIH研究の "effort preference" 解釈、微小血栓仮説は決着していない。二次情報(ブログ・患者団体・企業サイト)は立場が強く出るため、一次文献と分けて扱う。
2. **病態群の所見を健常者に外挿しない**。§4.4 のネットワーク所見の多くは MS・TBI・long COVID のものである。
3. **相関と因果**。ミトコンドリア指標の低下は原因か結果か、多くの場合まだ確定していない。
4. **疲労スケールの多くは主観**。§1.1 の乖離があるため、主観尺度のみのRCTは効果を過小にも過大にも評価しうる。
5. レッドフラグ(進行性の体重減少、発熱の持続、リンパ節腫脹、局所神経症状、労作時胸痛、失神)があれば自己管理の対象ではない。
