# 倦怠感 — 分子生物学から対応策まで

> 作成日: 2026-08-09 / 更新: 2026-08-09(軸別の検討 §3 を追加)
> 医学的助言ではなく文献の整理。個別の判断は医療者と。

## 0. この文書の立場

「倦怠感」は**症状名ではなく、少なくとも8つの異なる状態を包む袋**である。仮説どおり、この語には相当な部分がマスクされている。

構成は次の通り。

1. **§2 で袋を開ける**(8軸への分解)
2. **§3 で軸ごとに個別に追う**(見分け方・機序・原因・客観的確認・動く⇄休む・対応)← 本文書の中核
3. **§4〜§6 で軸を横断する共通レイヤー**(分子 / 生理 / 認知・脳ネットワーク)を掘る
4. **§7〜§9 で病態別のエビデンスと、動く/休むの分岐、治療・リハビリ**に落とす

依頼者が提示した仮説 — 体温上昇の代謝コスト、不動による血流低下、体力による境界の移動、ワーキングメモリ飽和、脳ネットワークの非効率化 — は**いずれも文献上の裏付けがある**。ただし効き方の大きさと成立条件が違う。それを §5・§6 で定量的に区別する。

---

## 1. 用語の整理

疲労研究では `fatigue`(自覚症状)と `fatigability`(疲労性=負荷で低下する性質)を分ける枠組みが標準化されている(Enoka & Duchateau)。fatigability はさらに2つに割れる。

| 概念 | 中身 | 測り方 |
|---|---|---|
| **Perceived fatigability**(自覚的疲労性) | 恒常性維持に関わる感覚の変化。心理状態と生理的余力に依存 | RPE、自己申告スケール |
| **Performance fatigability**(遂行的疲労性) | 客観的パフォーマンスの経時的低下。収縮機能と筋活性化に依存 | 最大随意収縮力、反応時間、タスク成績 |

重要なのは**この2つが乖離しうる**こと。「きついのに出力は落ちていない」「出力は落ちているのに本人は自覚していない」の両方が起こる。倦怠感の訴えを一元的に扱うと、この乖離が見えなくなる。

## 2. 「倦怠感」の分解 — 8軸

臨床的には次の軸を独立に評価すべきで、どれも日本語では「だるい」に圧縮される。

| # | 軸 | 中核の異常 | 見分けるサイン |
|---|---|---|---|
| 1 | **眠気**(sleepiness) | 睡眠圧・睡眠の質 | 座ると寝落ちる、仮眠で回復 |
| 2 | **消耗感**(fatigue proper) | 労作なしでも持続する消耗感 | 休んでも取れない、仮眠で回復しない |
| 3 | **運動不耐**(exercise intolerance) | 酸素供給・抽出・前負荷 | 軽い労作で動悸・息切れ・脱力 |
| 4 | **筋力低下**(weakness) | 神経筋 | 力が入らない(だるさとは別) |
| 5 | **認知的疲労**(cognitive fatigue) | 前頭前野・制御資源 | 頭が回らない、判断が雑になる |
| 6 | **アパシー**(意欲低下) | 前頭-線条体ドパミン系 | やる気の起点が立たない、苦痛感は薄い |
| 7 | **抑うつ・アンヘドニア** | 気分・報酬系 | 興味喪失、自責、日内変動 |
| 8 | **起立不耐** | 自律神経・前負荷 | 立位・座位維持で悪化、臥位で軽快 |

### 2.1 直交する修飾因子: PEM

軸とは別に、**PEM(労作後倦怠感, post-exertional malaise)** の有無を必ず判定する。「活動後に数時間〜数日**遅れて**出現し、活動量に不釣り合いで、回復に長時間を要する症状増悪」と定義される。PEMは8軸のどれかではなく、**どの軸にも乗りうる修飾因子**であり、後述する「動く/休む」の最大の分岐点になる。

### 2.2 軸は同時に立つし、連鎖する

実際には単一軸で説明できることは稀で、しかも**軸どうしが因果でつながる**。

- OSA → 眠気(1) + 消耗感(2) + 認知的疲労(5)
- 起立不耐(8) → 運動不耐(3) + 認知的疲労(5)(脳血流低下)
- 炎症 → 消耗感(2) + アパシー(6) + 認知的疲労(5)(サイトカイン→ドパミン経路)
- 不動 → 運動不耐(3) + 起立不耐(8) + 筋力低下(4)
- 抑うつ(7) → 不動 → 運動不耐(3) → さらに消耗感(2)、という自己増強ループ

だから軸別に見る目的は「1つに決めること」ではなく、**どの軸が上流でどれが下流かを見分け、介入点を選ぶこと**にある。

## 3. 軸別の検討

各軸について、**見分け方 / 中核機序 / 主な原因 / 客観的な確認 / 動く⇄休む / 対応** を通す。

### 3.1 軸1: 眠気(sleepiness)

**見分け方**
静かな状況で座ると寝落ちる。**20分程度の仮眠で明確に軽快する**。これが「消耗感」との最大の弁別点で、消耗感は仮眠では戻らない。

眠気と疲労が別構成概念であることは測定でも確認されている:
- ESS(主観的眠気)と MSLT(客観的入眠潜時)の相関は **rho ≈ −0.37** と弱い
- **FSS(疲労)と MSL は無相関** — 疲労は客観的眠気に影響しない
- FSS と ESS は **r ≈ 0.28** と弱い相関にとどまる

つまり主観尺度どうしでも眠気と疲労は分離する。ESS は「状況的な入眠傾向(trait)」、MSLT は「今この場で眠りに落ちる生理的能力」を測っており、そもそも別のものを見ている。

**中核機序**
覚醒の持続で前脳基底部にアデノシンが蓄積し、**A1受容体**を介して覚醒促進ニューロンを抑制する。断眠では A1受容体密度自体が上昇する(ヒトPET)。カフェインは A1/A2A 拮抗で「眠気の知覚」を消すが、**アデノシン蓄積そのものは進行し続ける**。カフェインが睡眠負債を返済しない理由がここにある。他にオレキシン系(ナルコレプシー)、概日位相のずれ。

**主な原因**
睡眠時間不足、閉塞性睡眠時無呼吸(OSA)、周期性四肢運動、ナルコレプシー、概日リズム睡眠障害(後退型)、薬剤(抗ヒスタミン、鎮静系、β遮断薬)、アルコール。

**客観的な確認**
ESS、2週間の睡眠日誌、アクチグラフ/ウェアラブル、いびき・無呼吸目撃・肥満・高血圧のスクリーニング、必要ならPSG/MSLT。

**動く⇄休む**
これは「休息」の問題ではなく **「睡眠」の問題**。安静にしても返らない。短時間仮眠(20分)は有効だが、長時間の安静臥床は無効かつ有害(§5.2 のデコンディショニング)。

**対応**
睡眠時間の確保、CBT-I(§9.2)、OSA治療、朝の高照度光、カフェインのタイミング管理(半減期は5時間前後なので午後は慎重に)。

### 3.2 軸2: 消耗感(fatigue proper)

**見分け方**
労作の有無にかかわらず持続する消耗感。**休息でも仮眠でも戻らない**。「眠くはないが動けない」。

**中核機序** — この軸が最も分子的に解明されつつある。
1. **免疫→脳**: IL-1β/IL-6/TNF → 脳血管内皮の PGE₂ → 体温調節中枢+神経細胞のGPCR、および**迷走神経求心路**。迷走神経切断で LPS 誘導の sickness behavior は消える。I型IFN・IFN-γ は筋細胞にも直接作用して疲労を誘導する(§4.3)
2. **キヌレニン経路とドパミン低下**: IDO1誘導 → トリプトファンがキヌレニンへ、加えて酸化ストレスによる BH4 枯渇 → カテコラミン合成低下 → 線条体ドパミン低下(§4.4)
3. **回復不能成分**: 労作量に応じて蓄積し短い休息では戻らない成分が、計算モデル上で分離されている(§6.1)
4. **メタ認知**: 内受容の予測誤差の慢性化 → 「身体を制御できていない」という信念(allostatic self-efficacy 低下)の一次反応が倦怠感(§6.5)

**主な原因**
感染後(ME/CFS、long COVID)、慢性炎症性疾患、貧血、甲状腺機能低下、悪性腫瘍、腎・肝疾患、薬剤性、うつ病、慢性の睡眠負債。

**客観的な確認**
FSS/CFQ などの尺度は主観であることを承知の上で。血算、フェリチン、TSH、HbA1c、腎肝機能、電解質、CRP、B12。レッドフラグ(体重減少、持続する発熱、リンパ節腫脹、夜間症状)。ただし**検査が方針を変えるのは約5%**で、初回正常なら闇雲な再検査は推奨されない(§7.4)。

**動く⇄休む**
**PEMの有無で真逆になる**。PEMなし+デコンディショニング型なら運動が最良の単一介入。PEMありなら漸増固定の運動は禁忌(§8)。

**対応**
可逆因子の除去(特に薬剤レビュー)、エネルギーマネジメント教育/3P、条件を選んだ運動。**この軸に対して確実に効く薬はほぼ存在しない**(§9.6)。

### 3.3 軸3: 運動不耐(exercise intolerance)

**見分け方**
「動くと」動悸・息切れ・脱力が出る。安静時は比較的保たれる。軸2(安静時も消耗している)との弁別点。

**中核機序** — Fick の式(VO₂ = 心拍出量 × 動静脈酸素較差)の各項が独立に壊れうる。
- **酸素供給側**: 貧血(酸素運搬能)、心機能、肺・換気
- **前負荷**: 心臓に戻る血液量の不足 = **preload failure**
- **酸素抽出側**: 末梢のミトコンドリア機能・毛細血管密度
- **換気コスト**: 呼吸仕事そのものの酸素コストと、呼吸筋メタボリフレックスによる四肢血流の横取り(§5.1)
- **筋内**: Pi 蓄積と Ca²⁺ ハンドリング破綻(§4.1)

Systrom らの**侵襲的CPET(iCPET)**は、この軸の分解に最も有用な知見を出している:
- ME/CFS 患者の**約90%に preload failure**(正常量の血液が心臓に戻らない)。POTS や小径線維ニューロパチーでも一般的
- **小径線維ニューロパチーの有病率**が ME/CFS で 66%、long COVID で 72% と一般人口より高い
- 神経血管調節障害 + **末梢の酸素抽出障害**の併存として説明され、自律神経障害・ガングリオノパチー・ミトコンドリア障害と関連づけられる
- 少量ピリドスチグミンが preload failure の一部に有用な可能性(**確立治療ではない**)

**主な原因**
デコンディショニング(最頻)、貧血、心不全・弁膜症、肺疾患、甲状腺、ミトコンドリア病、ME/CFS・long COVID、POTS、薬剤(β遮断薬による変時性不全)。

**客観的な確認**
安静時心拍と労作時心拍の応答、SpO₂、Hb、心電図・心エコー、可能ならCPET。**2日連続CPET**は PEM の客観化に使われるが、**それ自体が症状増悪を誘発する**ため適応を選ぶ。

**動く⇄休む**
PEMなし → 漸進的運動が治療そのもの。PEMあり → 心拍上限を設定した範囲内に留める。起立不耐が併存するなら臥位から(§8.3)。

**対応**
原因治療。デコンディショニング型は有酸素+レジスタンス。前負荷不全型は塩分・水分・圧迫衣・臥位運動。

### 3.4 軸4: 筋力低下(weakness)

**見分け方**
「だるい」ではなく **「力が入らない」**。本人が混同しやすいので、具体的な動作(椅子から立てるか、腕を上げ続けられるか、階段)で確認する。

**決定的に重要な下位分類 — 易疲労性の脱力(fatigable weakness)**
反復・持続する動作で**悪化し、休息で回復する**変動性の脱力、夕方・夜に悪化する — このパターンは**重症筋無力症を強く示唆する**。MG患者は「全般的な疲労や痛み」ではなく「特定筋群の変動性・易疲労性の脱力」を訴える。ここを取り違えると診断が数年遅れる。

鑑別: 先天性筋無力症候群、Lambert-Eaton症候群、ボツリヌス症、有機リン中毒、慢性進行性外眼筋麻痺を伴うミトコンドリア病、AIDP(ギラン・バレー)、運動ニューロン疾患、脳幹虚血。
なお **Graves病はMGと最も合併しやすい**甲状腺疾患で、臨床像も似るため、甲状腺機能亢進症の患者に新規の脱力・呼吸症状が出たら MG を鑑別に入れる。スタチンは MG を増悪させうる。

**その他の原因**
ICU-acquired weakness(重症疾患後の筋・神経障害)、サルコペニア、廃用性萎縮、スタチン筋症、甲状腺(亢進・低下とも)、ビタミンD欠乏、電解質異常(K, Ca, P, Mg)、副腎不全、ステロイド筋症。

**客観的な確認**
徒手筋力テスト(近位筋優位か遠位筋優位か)、握力、椅子立ち上がりテスト、CK、TSH、電解質、必要なら反復神経刺激・抗AChR/抗MuSK抗体、筋電図。

**動く⇄休む**
原因次第で**分岐が最も大きい軸**。廃用性なら負荷が治療。神経筋疾患(特にMG)では過負荷は増悪要因であり、汎用の「運動しましょう」は危険。

**対応**
原因治療が第一。廃用性ならレジスタンストレーニング + 蛋白質。

### 3.5 軸5: 認知的疲労(cognitive fatigue)

**見分け方**
身体は動くが「頭が回らない」。判断が雑になり、衝動的な選択(即時報酬・低努力)に傾く。

**中核機序**
- **局所代謝産物の蓄積**: 6時間の高負荷認知作業で**外側前頭前野(lPFC)のグルタミン酸濃度と拡散が上昇**、対照領域(視覚野)では上がらない。解釈は「資源の枯渇」ではなく**蓄積による当該領域の動作効率低下**(§6.2)
- **努力コスト計算のシフト**: 疲労は「回復可能成分」と「回復不能成分」の2状態としてモデル化され、いずれも報酬に対して努力を払う意思を下げる(§6.1)
- **ワーキングメモリ負荷**: 警戒課題の成績低下は WM負荷で悪化し、これは「退屈だから」説ではなく**「認知資源需要が高いから」説を支持する**(§6.3)
- **ネットワーク**: 視床-線条体-皮質ループの結合異常、白質・ミエリン障害(§6.4)

**主観と客観が乖離する軸**でもある。ある研究では、**課題回避行動と相関したのは客観的疲労であって主観的疲労ではなかった**。自己申告だけの管理は外す。

**主な原因**
長時間の高制御作業、睡眠負債、炎症、MS、外傷性脳損傷、化学療法後(chemo-fog)、long COVID、うつ・不安、薬剤。

**客観的な確認**
エラー率、所要時間、タスク切替コスト、推敲回数、決定の質。**成績指標を主観スコアと並べて記録する**のが実務上いちばん効く。

**動く⇄休む**
休息だけでは回復不能成分が残る。**負荷の再設計**が本命。

**対応**(§9.5 に詳細)
外部化・自動化で実効WM負荷を下げる、同種の高制御タスクを長時間連続させない、週・月単位の回復ブロック、重要な意思決定を疲労時に置かない。

### 3.6 軸6: アパシー(意欲低下)

**見分け方**
**意欲の欠如でありながら、感情的苦痛を伴わない**点が抑うつとの弁別点。本人は「つらい」より「なんとも思わない」と言う。周囲のほうが先に気づく。
**「外から促されれば動けるか」**が実務的な判別質問になる(後述の自己賦活欠損型では、外的手がかりがあれば行動できるのに自発的開始ができない)。

抑うつとは**解離しうる**。TBI では、うつを適切に治療した後に強いアパシーが後遺症として顕在化し、それが社会復帰の主障壁になる例が報告されている。

**中核機序 — Levy & Dubois の3サブタイプ**
アパシーは単一現象ではなく、前頭-線条体回路上で分離可能な少なくとも3型の最終共通経路とされる。

| サブタイプ | 責任部位 | 特徴 |
|---|---|---|
| **感情-情動型** | 眼窩内側前頭前野 → 腹側線条体 | 行動と情動的価値の結びつきが切れる |
| **認知型** | 背外側前頭前野 | 計画立案・実行機能の障害で行動が起動しない |
| **自己賦活欠損型** | 内側前頭前野・背内側線条体 | **外的に促されれば動けるが、自発的な思考・行動の開始ができない**。最重症型 |

画像研究では前部帯状回、腹内側/眼窩前頭皮質、腹側線条体とそのドパミン投射が一貫して関与する。§4.4 の「炎症→ドパミン低下」はこの軸に直接効く経路。

**主な原因**
神経変性疾患(AD、PD、前頭側頭型)、脳血管障害、TBI、慢性炎症、**抗うつ薬(SSRI)による薬剤性アパシー**(系統的レビューあり — 見落とされやすい)。

**客観的な確認**
アパシースケール、「促せば動くか」の観察、抑うつ尺度との突き合わせ(アパシーは高いのに抑うつは低い、というパターン)。

**動く⇄休む**
休息は効かない。**外的トリガーと構造化**が介入。

**対応**
日課の構造化、外的な起動キュー、社会的な巻き込み。薬剤性の見直し(SSRIの減量・変更)。メチルフェニデートは**中等度の反応性**が報告される(ドパミン・ノルアドレナリン再取り込み阻害により線条体・前頭前野の細胞外濃度を上げる)が、適応と副作用を選ぶ。

### 3.7 軸7: 抑うつ・アンヘドニア

**見分け方**
興味・喜びの喪失、自責、朝方に悪い日内変動、希死念慮。アパシーとの違いは**主観的苦痛の有無**。

**位置づけ**
プライマリケアで疲労を訴える患者の原因内訳で**うつが18.5%と最多カテゴリ**(重篤な身体疾患4.3%、貧血2.8%、悪性腫瘍0.6%と比べて桁が違う)。「見落としてはいけない身体疾患」ばかりを探して、最頻の原因を落とすのは典型的な失敗。

**中核機序**
§4.4 のとおり、炎症 → IDO1/キヌレニン + BH4枯渇 → ドパミン低下という**身体側からの経路**が存在する。「心因か器質か」の二分法自体が古い。Stephan の理論では、慢性的な dyshomeostasis に対する一次反応が倦怠感で、**慢性化した結果が抑うつ**という順序で説明される(§6.5)。

**客観的な確認**
PHQ-9 等、日内変動、睡眠パターン(早朝覚醒)、体重変化。

**動く⇄休む**
運動は抑うつにも疲労にも有効な数少ない介入。ただし**うつによる不動 → デコンディショニング → 運動不耐**のループに入っていると、初期の閾値設定を誤ると挫折する。

**対応**
標準治療。**注意点として、抗うつ薬自体が倦怠感・アパシー・眠気を作りうる**(§3.6)。「治療しているのにだるい」ときは薬剤を疑う。

---

### 3.8 軸8: 起立不耐(orthostatic intolerance)

**見分け方**
立位・座位の維持で悪化し、**臥位で軽快する**。シャワー、行列、長時間の会議で悪化。ブレインフォグが姿勢依存的に変動する。「何もしていないのに疲れる」の正体がこれである場合がある — 座位保持自体が負荷になっている。

**中核機序**
- 血漿量減少と**前負荷不全**(§3.3 の preload failure と地続き)
- 心室リモデリング: ベッドレストは**急性脱水では起きない**心筋の萎縮・スティフネス変化を起こす。小さく硬い心臓は Starling 曲線が急峻化し、起立負荷で1回拍出量がより大きく落ちる(§5.2)
- 自律神経障害、小径線維ニューロパチー
- 脳血流低下による認知症状

**主な原因**
POTS、起立性低血圧、長期臥床後、脱水、自律神経障害、ME/CFS・long COVID、貧血、薬剤(降圧薬、利尿薬、α遮断薬)。

**客観的な確認**
**起立試験 / NASA lean test** が自宅でも実施可能。臥位で安静後、起立(または壁にもたれて立位)10分間の心拍・血圧を測る。POTSの目安は**10分以内に心拍が30/分以上上昇**(起立性低血圧を伴わない)。ウェアラブルでも傾向は見える。

**動く⇄休む**
「立って歩く」を課すのが**最悪の初手になりうる**軸。§8.3 の通り、Levine/CHOP プロトコルでは最初の1〜2ヶ月を**厳密に臥位・座位**で行う。

**対応**
塩分・水分負荷、圧迫衣(腹部を含むもの)、臥位からの有酸素運動、必要に応じ薬物。**運動 + 容量負荷の併用**は運動単独より起立耐性の低下防止に有効という結果がある。

## 4. 分子生物学レイヤー(軸横断)

### 4.1 筋内で起きること(末梢性疲労)— 主に軸3・軸4

Allen–Lamb–Westerblad 系の細胞レベル研究が骨格。

- **無機リン酸 (Pi) の蓄積**が主犯格。PiがSR(筋小胞体)内に入り Ca²⁺ と沈殿することで**放出可能なCa²⁺が減る**。ラットでは張力低下は酸性化(H⁺)よりPi濃度と一貫して相関する。かつて主役とされた乳酸アシドーシスは主因から降格している。
- **ATP低下と Mg²⁺上昇**による SR Ca²⁺ チャネル(RyR1)開口効率の低下。
- **RyR1 の酸化・過リン酸化による Ca²⁺ リーク**。運動でRyR1はPKA過リン酸化され、加齢や慢性ストレスでは酸化的修飾により慢性的な漏出が生じる。ROSとリークの**フィードフォワード・ループ**を形成する。
- グリコーゲン枯渇、興奮収縮連関の障害、神経筋伝達。

末梢性疲労は「エネルギーが尽きる」より **「Ca²⁺ハンドリングが壊れる」** 現象として理解されている。

### 4.2 ミトコンドリアと細胞エネルギー代謝 — 主に軸2・軸3

- **WASF3**(PNAS 2023, ME/CFS): 患者の骨格筋生検で WASF3 タンパクの増加と ER ストレスの異常活性化。WASF3はアクチン重合を促してグリコリシスを駆動し、ミトコンドリア呼吸を抑制する。マウスでER ストレス誘導 → 複合体IV低下、ER ストレス阻害で WASF3 を下げると患者細胞のミトコンドリア機能が改善。「運動不耐の分子的説明候補」。
- **long COVID のミトコンドリア異常**: OXPHOS低下、構造変化、脂肪酸酸化障害。ME/CFS の所見と重なる。
- **PDH阻害仮説**(Fluge & Mella ら): 解糖からTCAへの入口が絞られ、アミノ酸異化に依存する代謝プロファイル。
- **NAD⁺/レドックス低下**。
- **イタコン酸シャント仮説**: 活性化マクロファージの代謝中間体イタコン酸がSDH(複合体II)を阻害し慢性的な代謝停滞を作るという提唱がある。**理論段階でヒトでの直接検証は弱い**ため、確立事実として扱わないこと。

### 4.3 免疫 → 脳(sickness behavior)— 主に軸2・軸5・軸6

「感染すると寝込む」のは副作用ではなく**進化的にプログラムされた行動**であり、倦怠感研究の最も確実な部分。

- IL-1β、IL-6 の産生量が、発熱・倦怠感・疼痛・気分低下・集中困難と相関する(ヒト実験)。
- TNF と IL-6 が脳血管内皮を刺激 → **PGE₂** 産生 → 体温調節中枢と、GPCRを介した神経細胞への直接作用で、発熱・痛覚過敏・食欲低下・warmth-seeking を起こす。島皮質でPGE₂が「病気であること」の統一表象を作るという報告も出ている。
- **迷走神経求心路**が末梢サイトカイン→中枢の主要ルート。迷走神経切断でLPS誘導 sickness behavior は消える。
- **I型IFN・IFN-γ は筋細胞に直接作用して疲労を誘導**する経路も報告されている。

倦怠感は「エネルギー不足の受動的結果」ではなく、**免疫系が行動を能動的に書き換えている出力**でもある。

### 4.4 トリプトファン → キヌレニン → ドパミン低下 — 主に軸2・軸6・軸7

炎症と「やる気が出ない」をつなぐ最も追跡されている経路。

1. IFN-γ 等が **IDO1** を誘導 → トリプトファンがキヌレニン経路へ流れる
2. セロトニン原料が減り、キヌレニン代謝物(キノリン酸など)が増える
3. 同時に炎症による酸化ストレスが **BH4(テトラヒドロビオプテリン)** を消耗させ、チロシン水酸化酵素の補酵素が枯れて**カテコラミン合成が落ちる**
4. 結果として**線条体ドパミンの低下** → 努力に対する報酬の割引率が上がる → アンヘドニア、易疲労、精神運動制止(Felger & Miller の "inflammatory malaise")

ME/CFSではキヌレニン産生量と症状重症度の相関が報告されている。がん関連疲労でも炎症性トリプトファン異化が疲労・貧血・抑うつと関連。
「炎症 → 意欲低下」は心理的な弱さではなく**神経化学的なコスト計算の変更**として説明される。

### 4.5 睡眠圧: アデノシン — 軸1

§3.1 参照。前脳基底部のアデノシン蓄積 → A1受容体 → 覚醒促進ニューロン抑制。断眠でA1受容体密度も上昇。カフェインは知覚を消すだけで負債は消えない。

### 4.6 認知的疲労の神経代謝 — 軸5

Wiehler ら(Current Biology 2022, n=39, 6時間の課題)は MRS で、**高負荷認知作業後に外側前頭前野のグルタミン酸濃度と拡散が上昇**し、視覚野では上がらないことを示した。解釈は「資源の枯渇」ではなく **「代謝産物の蓄積による局所効率の低下」**。この状態で経済的意思決定は衝動側に傾く。

### 4.7 血管・内皮・微小循環

内皮機能障害、微小循環の灌流低下、long COVID での微小血栓仮説などが議論されている。**再現性の議論が続いており**、確定所見として扱うべきではない。

## 5. 生理レイヤー — 提示された仮説の検証

### 5.1 仮説A「体温上昇 → 呼吸数増加・代謝過剰で身体の可用性が食われる」→ **成立する。定量も出せる**

**(a) 発熱の代謝コスト**
体温1℃上昇あたり代謝率は **約8〜13%増加**(古典的研究で約13%、小児TPN研究で11.3%/℃、教科書的には10〜12.5%)。酸素消費・心拍出量・換気需要・栄養需要がすべて上がる。40℃の発熱なら安静時代謝は約1.3〜1.4倍で、**寝ていても軽い運動相当の代謝を回している**。

**(b) 呼吸仕事そのもののコスト**
換気の酸素コストは安静時には全VO₂の数%だが、最大運動時には **VO₂max の 10 ± 0.7%**、呼吸筋の予備を使い切る被験者では **13〜15%**。さらに「重度→最大運動」の移行域では、**換気増加分のO₂コストが全身VO₂増加分の 39 ± 10%** を占める。

**(c) 呼吸筋メタボリフレックスによる血流の"横取り"**
呼吸筋の仕事が増えると交感神経性血管収縮を介して**四肢筋への血流が奪われる**。呼吸仕事と脚のO₂取り込みは逆相関する。心不全患者ではより顕著。

**(d) 高体温そのものによる中枢性疲労**
40℃環境・60%VO₂max の運動では、深部体温 40.0℃到達時に **随意的活性化率が 82% → 54% に低下**。一方で筋の総発揮力は保たれていた。**筋は動けるのに中枢が指令を出さなくなる**。局所筋温ではなく**深部体温**が決定因子であることも示されている。

→ **結論**: 「発熱時のだるさ」は少なくとも4経路の合算 — 代謝需要の底上げ、呼吸仕事の増大、呼吸筋への血流再配分、深部体温による中枢性抑制 — に加えて §4.3 のサイトカイン→PGE₂→行動変容が乗る。仮説は正しく、想定より多層。

### 5.2 仮説B「不動 → 血流低下」→ **成立する。ただし主役は"血流"より"血漿量と心臓の縮小"**

ベッドレスト研究(Dallas系列など)の代表的変化:

| 指標 | 変化 |
|---|---|
| 血漿量 | **−17%** |
| 肺動脈楔入圧(前負荷) | −18% |
| 1回拍出量 | −12% |
| 左室拡張末期容積 | −16% |
| 最高酸素摂取量 | **−33%** |
| 起立耐性 | −24% |

期間・プロトコルにより幅はあるが、順序は **血漿量減少(数日)→ 心筋の萎縮・スティフネス変化(1〜2週)→ 骨格筋・毛細血管・インスリン感受性(週単位)**。

重要な機序として、頭低位ベッドレストは**急性の脱水では起きない心室リモデリング**を引き起こす。心臓が小さく伸展性の低い状態になり Starling曲線が急峻化するため、起立負荷で1回拍出量がより大きく落ちる。**「単に水が減った」のではなく、ポンプの形状が変わる**。

対策として、運動単独より **運動 + 容量負荷(補液)の併用**のほうが起立耐性の低下を防げたという結果がある。

→ 直感は正しい。ただし介入設計上は「歩かせる」より **「臥位/座位の有酸素運動 + 塩分・水分で血漿量を戻す」** ほうが理にかなう場面がある(§8.3)。

## 6. 認知・脳ネットワークのレイヤー — 主に軸5・軸6

### 6.1 認知的疲労は「資源枯渇」ではなく「コスト計算のシフト」

Müller & Apps(Nature Communications 2021)の計算モデルでは、疲労は**2つの潜在状態**に分かれる:

- **回復可能な (recoverable) 成分** — 休息で戻る
- **回復不能な (unrecoverable) 成分** — 労作量に応じて蓄積し、短い休息では戻らない

両者とも「報酬のために努力を払う意思」を下げる。神経的には**運動野/前運動野の状態信号が島皮質(anterior insula)の努力価値計算に入力**し、これから払う努力の主観的価値を押し上げる。

実務的含意: **「休めば戻る疲労」と「休んでも戻らない疲労」は別物として蓄積している**ので、日次の回復だけを見ていると後者が静かに積み上がる。

### 6.2 神経代謝

§4.6 参照(lPFC のグルタミン酸蓄積)。

### 6.3 ワーキングメモリ容量は効くのか → **効く。ただし"容量"より"負荷と自動化"**

- 警戒課題(vigilance)の成績低下は、**同時のWM負荷で悪化**する。空間性・言語性どちらの負荷でも起こることから、共通の実行系資源を食い合っていると解釈される。
- 決定的なのは、この結果が **「退屈・低負荷だから注意が落ちる」説ではなく「認知資源需要が高いから落ちる」説を支持する**こと。**ワーキングメモリが埋まる → 疲れる**という直感は支持される。
- 主観的疲労と客観的パフォーマンス低下は**乖離する**。ある研究では、**課題回避行動と相関したのは客観的疲労であって主観的疲労ではなかった**。

### 6.4 IQは関係あるか → **直接の証拠は弱い。説明力があるのは別の変数**

「IQが高い人は認知的に疲れにくい」を直接支持する強い証拠は見当たらない。関連しそうな変数:

| 変数 | 疲労への効き方 | 確からしさ |
|---|---|---|
| **WM容量 / 流動性知能** | 同じ課題の相対負荷を下げる(容量に対する占有率が下がる) | 中程度。「疲れにくさ」の直接測定は少ない |
| **課題の自動化・熟達度** | 実行系の関与自体を減らす。おそらく**最大の効き** | 高い(スキル獲得研究一般) |
| **Need for Cognition / 自己制御** | 高いほど努力割引(effort discounting)が小さく、認知的要求を回避しにくい。努力回避による"安堵"も小さい | 中程度、再現あり |
| **Cognitive reserve** | 負荷・損傷・加齢に対する耐性の個人差 | 概念として確立、疲労特化の実証はこれから |

「認知的許容量」は **WM容量(ハード) × 自動化度(ソフト) × 動機づけ特性(値付け)** の積として考えるほうが実態に近い。IQを固定パラメータとして扱うより、**自動化と外部化で実効負荷を下げる**ほうが介入可能性が高い。

### 6.5 脳ネットワーク・可塑性 → **「非効率になっている」に対応する所見はある**

- **視床-線条体-皮質ループ**が中枢性疲労の中核として繰り返し同定される。MSでは、**皮質-皮質間および皮質下-皮質下間の結合は強い一方、皮質-皮質下間の結合が弱い**という所見があり、「制御ループの断線」として解釈される。
- 同様の striato-thalamo-cortical / 前頭ネットワークの統合性低下が、外傷性脳損傷後や高齢者の認知的疲労とも関連する。
- TBI後の病的疲労では、**時間経過とともに前頭前野ネットワークが分離(segregation)していく**パターンが報告される。「使うほど協調が崩れる」像。
- メタ解析レベルでも、精神的疲労の機能的相関としてこのループ群が横断的に浮かぶ。

**白質・ミエリン側**も無視できない。軽症呼吸器COVIDのモデルで、**CCL11 を介した白質選択的ミクログリア反応 → オリゴデンドロサイト前駆細胞とミエリンの喪失 → 伝導速度と軸索代謝の障害**という経路が示され、化学療法後の "chemo-fog" と共通機序として議論されている。持続的認知症状のあるヒトでも CCL11 上昇が確認され、海馬では神経新生の抑制も観察されている。

→ 「脳部位の可塑性やネットワークの動きが悪い/非効率」という仮説は、**(a) 代謝産物蓄積による局所効率低下、(b) ループの結合異常、(c) ミエリン・伝導の障害** という3水準で裏付けがある。ただしこれらは主に**病態群(MS, TBI, long COVID)**での所見で、健常者の日常的疲労にそのまま外挿はできない。

### 6.6 メタ認知説 — 倦怠感は「身体を制御できない」という推論の結果

Stephan らの **allostatic self-efficacy 理論**(2016):

1. 内受容(interoception)の予測誤差が慢性的に高い状態 = **dyshomeostasis**(身体信号についての驚きが慢性的に高い)
2. これをメタ認知層が監視し、「自分の脳は身体状態を制御できているか」という信念(**allostatic self-efficacy**)を更新する
3. この信念が低下した結果の一次反応が **倦怠感(軸2)**、慢性化した結果が **抑うつ(軸7)**、という順序で説明する

この理論の実務的価値は、**「炎症も貧血も検査で出ないのに強い倦怠感がある」状態に、心因論に逃げずに機序を与える**点にある。また「予測可能性を回復させる介入(ペーシング、記録、予測誤差の縮小)」が理にかなう理由も説明する。

## 7. 代表的な病態と、いま言われていること

### 7.1 感染後疲労: ME/CFS と long COVID

最も研究が集中し、同時に**最も論争的**な領域。

**筋レベルの直接証拠(Appelman et al., Nature Communications 2024)**
long COVID 患者に2日間CPETで PEM を誘発し、前後で筋生検を実施。PEM誘発後に:
- ミトコンドリア指標の即時かつ重度の低下
- 萎縮線維の増加
- 免疫細胞の広範な浸潤
- **骨格筋内のアミロイド含有沈着物の増加**

「気のせい」でも「単なるデコンディショニング」でもない**組織学的変化**が、労作閾値を超えた後に起きることを示した。この論文は運動療法の是非をめぐって Nature Communications 誌上で応酬(letter と reply)になっている。

**循環側の所見(Systrom ら, iCPET)**
§3.3 の通り、preload failure が ME/CFS の約90%に見られ、小径線維ニューロパチーの合併率も高い(ME/CFS 66%、long COVID 72%)。**軸3と軸8が同一の病態から生じている**ことを示す。

**NIH 深層表現型研究(Walitt et al., Nature Communications 2024)と "effort preference" 論争**
感染後ME/CFS患者を8年かけて多面的に評価。EEfRT課題で、同じ報酬条件下で患者は難易度の高い課題を選ばなかったとし、これを **"effort preference"(どれだけ努力したいか)** の差、「できると思っていることと身体が実行することのミスマッチ」と解釈した。
この解釈には強い批判がある — **同じ課題でも患者にとっての実コストは健常者より高いのに補正していない**という指摘。EEfRT の妥当性自体も議論の対象。**所見と解釈を分けて扱う必要がある。**

**治療試験の現状(2026年時点)**
- RECOVER-CT は13治療の登録を2025年に完了、RECOVER-TLC がバリシチニブ、低用量ナルトレキソン(LDN)、セマグルチド、星状神経節ブロックなどを検証中。**結果は2026年末までに出そろう見込み**で、現時点で確立治療と呼べるものはない
- LDN はメタ解析で疼痛に大きめ・睡眠に中等度の効果量が報告される一方、疲労への効果は未確定
- 英国の三剤併用試験は否定的結果

### 7.2 がん関連疲労(CRF) — エビデンスが最も整っている領域

- **非薬物が第一選択**。57件のRCTのメタ解析で**運動と心理的介入がともにCRFを減らし、両者に有意差なし**。ヨガ、マインドフルネス、心理社会的介入にも効果
- **メチルフェニデート**: 5試験426名で SMD −0.28、別のメタレビューで −0.48(95%CI −0.75〜−0.21)。**ASCOは条件付きで日常的使用に反対、NCCNは非薬物が不十分な場合の選択肢として残す**。効果が明確になるのは**5週以降**
- **明るい光療法**: 疲労に対する効果量は Hedge's g ≈ 0.47 で、睡眠指標への効果より大きいという報告

### 7.3 多発性硬化症(MS)の疲労 — 薬は効かなかった

**TRIUMPHANT-MS**(Lancet Neurology 2021, n=141, 4期クロスオーバー、二重盲検): **アマンタジン、モダフィニル、メチルフェニデートのいずれもプラセボに優越せず、有害事象はむしろ多かった**。長年の標準的処方を否定した重要試験。
→ MS疲労では**運動療法・エネルギーマネジメント教育・CBTなどの非薬物**に重心が移っている。

### 7.4 一次診療で見るべきもの

- プライマリケア受診者の**最大15%**が疲労を訴える
- 原因の内訳(系統的レビュー): **うつ 18.5%、重篤な身体疾患 4.3%、貧血 2.8%、悪性腫瘍 0.6%**。**多数派は単一の器質的原因では説明されない**
- **検査が方針を変えるのは約5%**。初回が正常なら闇雲な再検査は推奨されない。レッドフラグ(体重減少、発熱持続、リンパ節腫脹、夜間症状、局所神経症状)がなければ、**丁寧な問診 + 限定的な検査 + 経過観察**が合理的
- **鉄**: 非貧血の鉄欠乏に対する鉄補充は、**フェリチン ≤15 ng/mL の高度枯渇群でのみ**疲労改善が示された(Blood 2011)。フェリチン ≤50 µg/L の献血者405名を対象とした静注鉄のRCT(2020)では、ヘモグロビン・フェリチンは上がったが**疲労と全般的健康感は改善しなかった**。「フェリチンが低め=鉄を入れれば元気になる」は成り立たない

## 8. 「動いた方がいい」と「休んだ方がいい」の境界

### 8.1 最大の分岐は PEM の有無

```
倦怠感がある
├─ PEM あり(活動の12〜72時間後に不釣り合いな増悪、回復に日単位)
│   → 【休息側・ペーシング】漸増固定の運動療法は禁忌
│      NICE NG206(2021)は GET を推奨から削除。「症状を押して課題を完遂しない」
│      エネルギー封筒の内側に留まることを原則とする
│
├─ PEM なし + デコンディショニング型(不動・入院後・術後・加齢)
│   → 【運動側】漸進的運動が最も有効な単一介入。§5.2 の変化は可逆
│
├─ PEM なし + 起立不耐が主(軸8)
│   → 【臥位から始める運動】+ 容量負荷(§8.3)
│
├─ 急性感染・発熱中
│   → 【休息】§5.1 の代謝コストが乗っており、心筋炎リスクもある
│      解熱後、症状が消えてから段階的に戻す
│
├─ 神経筋疾患が疑われる(軸4の易疲労性脱力)
│   → 【まず診断】汎用の運動処方の前に鑑別。MGでは過負荷が増悪要因
│
└─ 認知的疲労が主(軸5)
    → 【負荷の再設計】休息だけでは回復不能成分が残る。§9.5 へ
```

**PEMの有無を最初に判定する**という順序が、この10年で最も大きく変わった実務上の点。

### 8.2 体力(予備能)は境界をどう動かすか

「体力による影響はありそう」という直感は正しく、機序も明確:

- 同じ**絶対**負荷でも、VO₂max が高い人ほど**相対**負荷(%VO₂max, %心予備能)が低い。§5.1(c) の呼吸筋メタボリフレックスも §4.1 の代謝産物蓄積も、**相対強度で決まる**
- 血漿量・心室コンプライアンスが大きいほど、起立負荷や熱負荷に対する余裕が大きい
- したがって**同じ「30分の散歩」が、ある人には回復刺激、別の人には閾値超え**になる

**含意**: 活動量は絶対量(分数・歩数)ではなく **相対強度(心拍・RPE・会話可能性)** で規定すべき。

### 8.3 実務的な閾値の置き方

| 状況 | 目安 |
|---|---|
| **PEMのある人** | 心拍上限を設定(嫌気性閾値以下、簡易には「安静時心拍 + 15」や「(220−年齢)×0.55〜0.6」など個別化)。ウェアラブルでアラート。活動を短いブロックに刻み、**予定的に**休む(疲れてから休むのでは遅い) |
| **起立不耐** | **臥位・座位から開始**。Levine/CHOP プロトコルでは最初の1〜2ヶ月は**厳密に臥位・座位**(リカンベントバイク、ローイング、水泳)。トレッドミルや階段は使わない。3ヶ月で改善、6ヶ月まで漸増。塩分・水分・圧迫衣を併用 |
| **デコンディショニング** | 会話可能ペース(talk test)、Borg RPE 11〜13。週単位で漸増 |
| **共通の中止基準** | 翌日〜翌々日に持ち越す増悪が出たら、直前の負荷が閾値超え。**2〜3日の遅発を見るため、活動ログは最低3日窓で評価** |
| **暑熱下** | 深部体温が効くので(§5.1d)、環境温・湿度を独立変数として記録。冷却(プレクーリング、冷水摂取)は中枢性疲労を後ろにずらす |

## 9. 治療・リハビリ・対応策

### 9.1 まず可逆因子を潰す

- **薬剤レビュー**(β遮断薬、抗ヒスタミン薬、鎮静系、**SSRI由来のアパシー**、降圧薬)— 最も見落とされ、最も可逆
- 血算、フェリチン、TSH、HbA1c/血糖、腎肝機能、電解質、CRP、B12、必要に応じてセリアック、OSAスクリーニング
- **うつ・不安の評価**(頻度が最も高いカテゴリ)
- アルコール、カフェインのタイミング

### 9.2 睡眠(軸1)

- **CBT-I** が第一選択。不眠重症度と**疲労の両方に大きい効果**。睡眠効率 +8〜16%、入眠潜時 −30〜45分。ただし睡眠制限期に**一時的に疲労が増える**ことを事前に説明しないと脱落する
- OSA の治療
- **高照度光療法**: 疲労への効果量 g ≈ 0.47。朝に使う

### 9.3 運動処方(§8の分岐に従う)

- デコンディショニング型・がん関連疲労: **運動が最良の単一介入**。有酸素 + レジスタンス
- 起立不耐: 臥位開始の Levine/CHOP + 容量負荷
- PEM型: **漸増固定の運動プログラムは行わない**。客観指標(心拍)で管理された範囲内の低強度活動に留める

### 9.4 ペーシング / エネルギーマネジメント(軸2・軸3)

作業療法士主導の**エネルギーマネジメント教育(EME)**は、MS・慢性疾患・long COVID で自己効力感、疲労の生活影響、QOLの改善が示されているマニュアル化された介入。中核は **3P**:

- **Pacing**(配分): 活動と休息を予定に組み込む。「疲れる前に休む」
- **Planning**(計画): 高負荷タスクを日内の余力ピークに配置、分散
- **Prioritizing**(優先): 捨てるものを先に決める

§6.6 の枠組みで見ると **「内受容の予測誤差を減らして allostatic self-efficacy を回復させる」介入**として理解できる。記録して予測可能にすること自体に効果がある。

### 9.5 認知的負荷のマネジメント(軸5)

| 原理 | 施策 |
|---|---|
| WM占有を減らす(§6.3) | 外部化(書く、チェックリスト、記憶に頼らない)。**同時保持項目を減らす**設計 |
| 実効負荷は自動化度で決まる(§6.4) | 頻出タスクは手順を固定してテンプレ化・自動化。「毎回考える」を潰す |
| 代謝産物の蓄積(§4.6) | 長時間の連続制御作業を避ける。**同種の高制御タスクを6時間続けない**。異種タスクへの切替は蓄積部位を変える可能性がある |
| 回復不能成分がある(§6.1) | 日次の休息では戻らない蓄積があると前提し、**週・月単位の回復ブロック**を確保 |
| 主観と客観が乖離(§6.3) | 自己申告だけで判断しない。**成績指標(エラー率、所要時間、判断の質)**を併記して記録 |
| 疲労時は衝動側に傾く(§4.6) | 重要な意思決定・コミット・購買を**疲労時に置かない**ルール化 |

### 9.6 薬物療法の現状

| 対象 | 薬 | 現状 |
|---|---|---|
| MS疲労 | アマンタジン / モダフィニル / メチルフェニデート | **3剤ともプラセボ非優越、有害事象多い**(TRIUMPHANT-MS)。無差別使用は支持されない |
| がん関連疲労 | メチルフェニデート | 効果量 −0.28〜−0.48。ASCOは条件付き反対、NCCNは選択肢。効果発現は5週以降 |
| アパシー(軸6) | メチルフェニデート | 中等度の反応性。**まずSSRI等の薬剤性アパシーを除外** |
| 非貧血の鉄欠乏 | 経口/静注鉄 | フェリチン ≤15 の高度枯渇でのみ疲労改善。≤50 では改善なし |
| 起立不耐 / POTS(軸8) | 塩分・水分負荷、圧迫衣、ミドドリン、β遮断薬少量 | 非薬物(容量負荷+臥位運動)が土台 |
| preload failure(軸3) | 少量ピリドスチグミン | 一部で有用の可能性。**確立治療ではない** |
| long COVID / ME/CFS | LDN ほか | **確立治療なし**。RECOVER-TLC 等の結果待ち(2026年末) |

**総括すると、倦怠感に対して確実に効く薬はほぼ存在しない。** 効果が確立しているのは、原因疾患の治療、睡眠の是正、条件を選んだ運動、エネルギーマネジメントである。

### 9.7 心理・行動

- **CBT** は ME/CFS では**補助的であって治癒的ではない**とNICEが明示。がん関連疲労では運動と同程度に有効
- **マインドフルネス**: 神経疾患の疲労に対して g ≈ −0.37(中等度)、がんサバイバーの疲労と活力にも有意な改善
- 病態説明そのもの(何が起きているかを理解すること)が予測誤差を下げるという理論的根拠がある(§6.6)

## 10. 自己観察のためのログ設計

倦怠感は「一つの量」ではないので、単一スコアで追うと必ず情報が落ちる。**§2 の8軸をそのまま列にする**のが基本設計。

| カテゴリ | 項目 | 理由 |
|---|---|---|
| 分解 | **8軸をそれぞれ0-10**(眠気/消耗感/運動不耐/筋力/認知/意欲/気分/起立時) | 軸ごとに原因も対応も違う(§3) |
| 客観 | 安静時心拍、HRV、睡眠時間・効率、歩数、**起立時心拍上昇** | 主観と客観の乖離を検出(§6.3)、軸8のスクリーニング |
| 負荷 | 身体活動の**相対強度**(心拍/RPE)、認知的高制御作業の連続時間 | 絶対量では閾値が決まらない(§8.2) |
| 環境 | 気温・湿度、体温 | 深部体温が中枢性疲労の決定因子(§5.1d) |
| 遅発 | **翌日・翌々日**の症状 | PEM は12〜72時間遅れる(§8.3) |
| 成績 | エラー率、所要時間、決定の質 | performance fatigability を捉える(§1) |

分析は**3日窓のラグ相関**で見る。当日の相関だけを見ると PEM を見逃す。軸ごとに別々に相関を取ると、「認知的疲労は連続作業時間に、消耗感は前々日の活動強度に、眠気は睡眠効率に効く」といった**軸ごとに異なるドライバー**が見えてくる。

## 11. 留意点(この分野を読むときの注意)

1. **論争が多い領域である**。特に ME/CFS・long COVID の運動療法、NIH研究の "effort preference" 解釈、微小血栓仮説は決着していない。二次情報(ブログ・患者団体・企業サイト)は立場が強く出るため、一次文献と分けて扱う
2. **病態群の所見を健常者に外挿しない**。§6.5 のネットワーク所見の多くは MS・TBI・long COVID のもの
3. **相関と因果**。ミトコンドリア指標の低下は原因か結果か、多くの場合まだ確定していない
4. **疲労スケールの多くは主観**。§1 の乖離があるため、主観尺度のみのRCTは効果を過小にも過大にも評価しうる
5. **8軸の分解は臨床現場の標準的な分類ではなく、本文書での整理**である。ただし各軸の弁別(眠気/疲労、アパシー/抑うつ、疲労/易疲労性脱力)は、それぞれ独立した文献的根拠を持つ
6. レッドフラグ(進行性の体重減少、発熱の持続、リンパ節腫脹、局所神経症状、労作時胸痛、失神)があれば自己管理の対象ではない
