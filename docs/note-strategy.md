# note 運用方針(19770104)

自動化スクリプト(`scripts/note_post.py` / `scripts/note_lint.py`)が何のために作られているかの前提。
別ツールで検討した内容をここに集約し、原稿の書き方とチェック項目の根拠にしている。

## アカウントの軸

**大学病院の理学療法士が、脳神経リハ・臨床思考・医療職のAI活用を実践的に書く note。**

- 想定読者: 若手〜中堅のリハビリ職(PT・OT・ST)
- 差別化の核: 「大学病院」「理学療法士」「脳神経内科・脳神経外科」「AI」の組み合わせ
- 一般向けの健康情報(姿勢改善など)は主軸にしない。読者は広がるが、医療広告・安全性の配慮が増え、差別化もしにくい

### テーマの優先順位

1. **医療・リハビリ職のためのAI活用** — 成長分野に現場理解を掛け合わせられる。最優先
2. **若手リハ職向け「脳神経リハの臨床思考」** — 専門性を直接売れる。読者数は限られるためテンプレート・確認表を添える
3. **医療職のキャリア・副業・働き方** — 購入動機は強い。ただし実績が出るまでは「教える」ではなく「実践記録」として書く

## 既存記事の扱い

削除しない。検索流入と過去の反応を残したまま、マガジンで整理する。

- 人間を考える(意志・時間・社会・生き方)
- リハビリテーションの未来を考える
- 理学療法士とAI(今後の主軸)
- 姿勢とセルフケア / 認知症・脳神経リハ / 組織とキャリア

新着記事だけを主軸テーマに統一し、プロフィールと固定記事で方針転換を説明する。

## 無料・有料の設計

| 位置 | 扱い |
| --- | --- |
| 1〜7本目 | 無料。信頼と反応の確認 |
| 8本目 | 無料。有料記事の予告と需要確認 |
| 9本目〜 | 最初の有料候補。980〜1,980円を想定 |

- 有料記事には「情報」だけでなく、**そのまま使えるもの**(プロンプト集・チェックリスト・テンプレート・記入例・失敗例)を含める
- メンバーシップは有料記事が数本売れ、反応を確認してから検討する
- 個別症例への医療相談・診断にあたるサービスは提供しない

> 市場データ(成長ジャンル・平均単価など)は別ツールでの調査に基づく引用で、**このリポジトリでは未検証**。
> 記事中で数値を引用する場合は note 公式発表などの一次情報を自分で確認すること。

## 自動化する範囲

医療テーマのため、**完全自動公開はしない。**

```
テーマ選定 → 調査 → 原稿作成 → 経験・見解の追記
  → 公開前チェック(scripts/note_lint.py)
  → note へ下書き保存(scripts/note_post.py)
  → 人間が目視確認 → note 上で公開
```

| 自動化する | 人間が行う |
| --- | --- |
| 原稿の流し込み、既存記事の上書き | 医学的妥当性の確認 |
| タイトル・タグの設定 | 患者情報・所属規程の確認 |
| 定型句・断定表現・出典欠落の検出 | 引用の妥当性、経験談の事実確認 |
| 公開前確認票の生成 | 見出し画像の設定と公開ボタン |

そのため `config/note_accounts.json` の `allow_publish` は `false` を既定にしている。

## 文体ルール

原稿を書くとき、および `scripts/note_lint.py` が見ているもの。

- **主語「私は」を使わない。** 誰の判断かは文脈と語彙で示す(「学生の頃」「ポスター制作を補助した際」など)
- 同じ書き出しの文を続けない
- 定型句を置かない — いかがでしたか / まとめると / 結論から言うと / ではないでしょうか / 深掘り / 本質的に / 言っても過言ではない
- 「AではなくB」型の対比を繰り返さない
- 文の長さを揃えない。短い文を混ぜる
- 一文は100文字以内を目安にする
- 感嘆符・絵文字は使わない

## 書いてはいけないこと

`note_lint.py` が「重大」として止める項目。

- 治癒・改善の断定(「必ず治る」「確実に改善」)
- 診断行為・受診回避の示唆
- 服薬の変更・中止の示唆
- 個別症例と読める記述(「68歳男性」「症例A」)、診療録・担当患者への言及
- 所属施設が推定できる記述(「当院」「勤務先の病院」)

「要確認」として警告する項目。

- 断定・一般化(必ず / 絶対に / 誰でも)、最上級表現(日本初 / 最高の)
- 研究・数値に触れているのに出典URLがない
- タイトルの一人称

## 記事のストック

- 医療職が生成AIを使う前に決めたい境界線(入力してはいけない情報)
- 理学療法士が生成AIで論文を読むときの確認手順
- 症例検討の抜けを減らすAI質問テンプレート
- 新人指導資料を生成AIで作る流れ
- 脳神経リハの勉強で最初に整理したい項目
- AIが作った医学記事の誤りを見抜くチェックリスト
- 有料版: リハ職向けAIプロンプト・確認表セット
