# 芥川寅之介 — アカウントの方向性

note: https://note.com/akutagawa_tora

読んだ本の紹介ではなく、**「役に立つ」の外側を、本と生活から考える**アカウント。

## 中心にある問い

> 意志して作る価値とは別に、世界との関係から生まれてしまう価値を探す

違和感の側にあるもの: 役に立つことばかり求められる / 生活まで生産や自己投資になる /「自分で決めて努力する」ことが過度に称賛される / 他者の評価が行動の上流に入り込む / 人間や経済を中心に世界を説明しすぎる。

惹かれている側にあるもの: 魅せられて動く衝動 / 意志以前の中動態 / 流れに沿う無為 / 後から成立する贈与 / 役に立たないものが持つ価値 / 人間を特権化しない視点 / 仕事に回収されない生活と読書。

## 独自性

強みは哲学の解説そのものではなく、**抽象的な思想を、生活と身体に一度通して考える**こと。本で得た概念・過去の経験・臨床で感じてきたこと・サーフィンなどの身体経験・技術への関心を往復させる。

例: 「無為」を辞書的に解説せず、「波は作れない。しかし波を読み、位置を取り、乗ることはできる」という身体経験から考える。

**臨床の側にも同じ構造がある。** 神経難病や血液がんのリハビリでは、病の進行そのものを止められない場面がある。それでも読み、位置を取り、できることをする。サーフィンの比喩より重く、この往復こそがこのアカウントの独自性の中心にある。

治る人だけでなく**治らない人と関わり続ける**経験は、成果で価値を測る見方が最初に崩れる場所でもある。

## 想定する読者

哲学の専門家ではなく、**働きながら今の生き方に何か違うと感じている人**。

仕事はしているが生産性だけを追うことに違和感がある / 哲学に興味はあるが専門書の解説だけでは生活につながらない / 自分らしく生きようとしてかえって疲れている / 読書を自己投資にしたくない / 答えより考えるための言葉がほしい。

## 書き手の時系列

記事は自分の経験を軸に書くため、出来事の順序を取り違えると本文が事実と食い違う。**推測で補わず、ここを参照する。**

1. 結婚
2. オーストラリアへワーキングホリデー
3. リハビリ病院で働きながら、大学院前期課程への進学を考え、**名古屋大学の研究生**になる
   - 研究テーマは「筋損傷からの回復を促進させる物理刺激を、分子生物学的に解明する」
   - 試験に受かれば翌春から入学して研究を続ける予定だった
4. **大学院受験に失敗。** 翌春から名大に出入りできなくなると考えた
5. **名大病院職員になれば名大の実験施設を使えるだろうと考えて転職。** 働きながら**博士前期課程**へ進学 — **この時期にサーフィンをやめる**
6. **博士後期課程**へ進学
7. **離婚**(課程の途中)
8. 博士後期課程を満期退学(コロナ禍と重なる)
9. **サーフィンとスノーボードを再開**

**分子生物学的な研究そのものが好きで、これは一貫している。** 施設を使うために移ったのは、研究を続けたかったからで、研究は課程のあいだ続いた。転職を「研究をあきらめて臨床へ移った」と読むのは誤り。

そのうえで、移った先では移った理由とは別の方向にも経歴が育った:

- 大学病院は急性期病院であり特定機能病院で、学ぶことが多かった
- 脳神経外科・脳神経内科・老年内科・血液内科・糖尿内分泌内科を主に担当するチームリーダーを経て、**現在は管轄主任**
- ALS などの神経難病、脳腫瘍、白血病などの血液がんの患者のリハビリに携わる
- 病気の受け入れの過程、本人の葛藤、家族の葛藤に立ち会う。**うまく治る人と、そうでない人の両方と関わる**
- 医師や大学院修了者など、考える相手が多い環境。治験に関わることもある
- 人工呼吸器のホースが引っ張られると解除が大変なため、引っ張られない仕組みの装置を考え、**特許申請に携わった**

記事に書くときの注意:

- 大学院時代は**働きながら**の在学で、かつ**結婚していた期間**。生活を切り詰めた話は、一人の時間管理の話ではない
- **離婚は在学中**。修了後ではない。再開は課程を終えたころ
- **4〜5はまだどの記事にも書いていない。** 転職の理由が「実験施設を使い続けるため」だった点は、このアカウントの中心の問い(魅せられて動く衝動)と直結する。記事01が描く「用途で選別する自分」では説明できない一手なので、扱いを決めてから書く

どこまで公開するかは記事ごとに判断する。現時点では、記事02で結婚していたことに触れ、記事04で離婚を明示している(記事01は時期のみで理由は書かない)。

**臨床の背景をどこまで書くかは `docs/note/DISCLOSURE.md` にまとめてある。** 施設名・役職・特許は書かない。診療領域は書いてよい。`note_lint.py` が公開範囲を検査する。

## 記事の型は2つ

読んだ本の数に記事の数が縛られると、10本そろえる前に止まる。型を2つ持ち、交互に出す。

| 型 | 軸 | 読書速度に | 未読の本の扱い |
|---|---|---|---|
| **書評** | 読んだ本1冊と自分の経験の往復 | 縛られる | 末尾で「これから読む」として置く |
| **地図** | 経験と問い。読む順番とその理由 | **縛られない** | 記事の主役。未読であることを明示する |

地図型で書くのは「なぜこの順で読もうとしているか」という理由づけで、**これは読んでいなくても書ける本人固有の内容**。読んだ本が次にどの本を要求したのかを辿る。

ただし**周辺図書のリストそのものを記事にはしない。** 記事01が「棚に並ぶ本も、まだ活用できていない資産のように見えてくる」と書いている以上、未読本の一覧を並べるだけの記事は看板と食い違う。

未読の本の書き方は `STYLE.md` を参照。

## 記事の基本構成

1. 自分の生活で起きた具体的なこと
2. そこにあった、まだ名前のない違和感
3. 本の中で見つけた概念
4. その概念で経験を読み直す
5. それでも残る疑問

結論を教えるのではなく、**本を読んだことで問題の見え方がどう変わったか**を書く。

## 記事の展開

公開順の候補。短い商品紹介を量産するより、独自の経験を含む書評を積む。

1. なぜ、忙しかった頃の私は本が読めなかったのか(三宅香帆『なぜ働いていると本が読めなくなるのか』)

## Amazon アソシエイトの扱い

**現状は未参加。通常の商品リンクのみを置く。** 紹介料は発生しない。

参加者表示(「Amazonのアソシエイトとして、芥川寅之介は適格販売により収入を得ています」)は、**専用リンクに差し替えるまで掲載しない。** 未参加の段階で掲載すると事実に反する。

`note_lint.py` がこの食い違いを両方向で検査する。

- 専用リンク(`tag=` 付き)があるのに参加者表示が無い → 運営規約が求める表示の欠落
- 参加者表示があるのに専用リンクが無い → 事実に反する記述

申請の順序は、公開記事を10本そろえてから。申請後180日以内に3件の適格販売が必要なため、記事ゼロの状態で審査の時計を始めない。
