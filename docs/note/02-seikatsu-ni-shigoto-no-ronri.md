# 生活に仕事の論理を持ち込むと、夫はなぜ黙るのか

三宅香帆さんの『なぜ働いていると本が読めなくなるのか』を読み、大学院時代に本を読めなくなった生活を振り返ると、仕事や研究へ時間を使いすぎたという量の問題よりも、生活のほぼ全域を、将来の成果へ変換できるかどうかで判断していたことが気になった。眠るなら翌日の能率のため、運動するなら健康のため、本を読むなら研究か仕事のためという具合に、生活の一つひとつへ目的と効用を求め、その目的を説明できないサーフィンや読書を、自分の生活から外していたからである。

続けて『「夫婦」不在社会』を読むと、そのとき見えていた問題が、個人の時間管理から二人の関係へ広がった。本書は、昭和から令和にかけて多くの人が見てきた小説、ドラマ、映画を読みながら、日本の物語において夫婦がどのように描かれ、あるいは描かれないまま残されてきたかを考える本であり、仕事と家庭を分担する制度の話だけでなく、生活を共にしているはずの男女が、なぜ言葉を交わせなくなるのかを、物語の中に現れた沈黙や不在からたどっている。

この本を読みながら、夫婦の会話について考えるより先に、仕事で身につけた論理を家庭へ持ち帰った側が、なぜ肝心なところで黙ってしまうのかを考えていた。

## 生産の場と生活の場では、正しさの働き方が違う

仕事では、目的を決め、役割を分け、期限を置き、できたこととできなかったことを確認する必要があり、複数の人が限られた時間で働く以上、誰が何を担うかを曖昧にしたままでは困る場面も多い。病院で働いていれば、判断の根拠を示し、相手へ伝わる形に整え、患者にとって必要な行為を選ばなければならないので、論理や効率を仕事の敵だとは考えていない。

しかし、仕事で役に立つ判断の仕方を、そのまま生活へ持ち込むと、二人の関係は、正しい側と間違った側、効率よく動く側と足を引っ張る側に分かれやすくなる。家事の手順や時間の使い方を話していたはずなのに、いつの間にか、合理的に説明できる人のほうが強くなり、言葉にするまで時間がかかる感情や、本人にも理由の分からない疲れは、説明できない側の未熟さとして扱われる。

論理の正しさが、存在の強弱へ変換されるのである。

もっとも、正しい側が話し続けられるかというと、そうとも限らない。仕事で使ってきた言葉は、目的を示し、手順を分け、達成の可否を確かめるために整えられてきたもので、そこには、理由の分からない疲れや、まだ言葉になっていない気配を扱う語彙が入っていないため、そうした話題が食卓に出た瞬間に、こちらの側も話す手立てを失う。

大学院時代に生活から外していったものを思い出すと、あのとき手放したのは時間だけではなく、成果へ変換できない出来事を語るための言い方のほうだったのかもしれない。仕事の言葉しか持たずに家へ帰れば、正しく話せる話題については話し続け、それ以外については黙るという分かれ方になり、黙っているあいだ、相手の目には関心がないように映る。

臨床や教育では、伝えた内容が相手に届かなかったとき、相手の理解力だけを問題にせず、自分の伝え方や、話す順序や、相手が置かれている状況を見直してきたつもりだが、家庭の中では、正しい説明をしたという事実に寄りかかり、その説明を受け取れない相手の側へ原因を置くことが起こりうる。正しさを確認する仕組みを持つ仕事より、関係そのものが場を支えている生活のほうが、正しさの使い方には注意が要るのだと思う。

三宅さんが多くの物語から拾い上げる夫婦の沈黙を、ここでは生活と生産の言葉のずれとして読んだ。本書が描くすべての夫婦を一つの原因で説明することはできないが、外で働く夫が、生産の場で身につけた言葉を家庭の中で使えずに黙る姿や、黙っていることを自分では選んだつもりでいる姿や、生活を支えてきた側の言葉を受け取れない姿は、夫婦に会話が足りないという助言だけでは捉えきれない。二人が話すために使える共通の言葉を、社会の側が育ててこなかったという問題が残るからである。

## 「生活が下手だった」という記憶が変わった

前の書評では、大学院時代に本が読めなくなり、サーフィンも運動もやめた経験を書いたが、あの時期は結婚していた期間でもあった。『「夫婦」不在社会』を読んだことで、当時の記憶にもう一つの見方が加わった。生活をうまく回せなかったという記憶の奥で、当時の自分は仕事と研究に使う生産の文法だけを持って二人の生活へ入り、その文法で扱えない時間を減らすことで両立させようとしていたのではないか。

課題を終える、知識を増やす、研究を進めるという行為には、達成したかどうかを確かめる基準があるが、本を読み、海へ行き、家族と夕食をとる時間には、同じ基準を置きにくい。読書から何を得たのか、海へ行って何が上達したのか、夕食の会話が何を生み出したのかと尋ね始めれば、生活は成果を報告する小さな仕事へ変わり、報告できない時間から順に削られていく。

その削減は、自分の意志で行っていた。誰かにサーフィンをやめろと言われたわけでも、本を読むなと命じられたわけでもないので、自分で目標を選び、必要な努力をしたという理解にも間違いはない。それでも、自分の意志だと感じていた選択に、仕事を優先し、能力を高め、将来の成果のために現在を使う人間を望ましいとする社会の言葉が入り込んでいたと考えると、当時の生活は個人的な失敗だけでは説明できなくなる。

三宅さんの前著は、本を読めなくなる人の背後にある労働の歴史を示し、『「夫婦」不在社会』は、生活を共にする二人が言葉を失うまでの過程を、物語の歴史から照らしている。私にとって二冊は、生産の側へ多くの時間と言葉を与えた社会が、趣味や家庭を含む生活の側へ何を残したのかを考える、連続した仕事として読めた。

## ワーク・アズ・ライフという言葉への警戒

私は仕事と生活を分けて考えるより、仕事も生活の一部として扱う「ワーク・アズ・ライフ」という感覚に惹かれてきた。臨床で得た問いを本で考え、読書で出会った概念を仕事へ持ち帰り、AIを使った制作も遊びも一つの生活の中で行うなら、勤務時間と余暇を機械的に切り分けるより、自分の実感に近いからである。

ただし、『「夫婦」不在社会』を読んだ後では、仕事と生活を一つにするという言葉に、二つの向きがあることを無視できない。生活で育った感覚や関係の持ち方が仕事へ流れ込み、仕事の場でも相手の反応や、その場で起きていることを受け取れるようになる向きと、仕事で求められる効率や評価が生活へ流れ込み、休息も趣味も家族との時間も、成果を出すための資源として管理される向きである。

大学院時代に生きていたのは、後者だった。仕事と研究を生活から分けなかった結果、生産の論理が生活を併合し、本やサーフィンのように成果を予測できない時間が消えたのであり、同じことが夫婦の間で起きれば、二人で過ごす時間まで家事、育児、仕事の分担を処理する会議になり、関係を確かめるための会話にも結論や改善を求めるようになる。

仕事と生活を混ぜるか、分けるかだけを決めても、この問題は解けない。どちらの言葉がどちらへ流れ込んでいるかを見なければ、自由に見える融合が、仕事による生活の全面的な占領になる。

## 一人に求めすぎないための関係

私は以前、結婚相手へ多くを求めすぎず、依存先を複数持ち、その時期に応じて比重を変えればよいと後輩へ話したことがある。その考えの背景には、オーストラリアで暮らしたとき、仕事を終えて家族と夕食をとる生活をよいと思う一方で、家族という共同体も永遠に同じ形で続くとは限らず、関係が機能しなくなれば組み替えられるものとして見た経験があった。

夫婦を唯一の依存先にしなければ、相手は自分の仕事、趣味、友人関係、感情の処理まで引き受ける必要がなくなり、二人の関係にかかる圧力も減るだろう。しかし、依存先を分散するという考えを投資の言葉だけで語れば、人との関係を故障に備えたポートフォリオとして管理し、都合が悪くなれば配分を変えるという、生産の文法へ戻る危険もある。

関係を一つに集中させないことと、関係を交換可能な資産として扱うことの間には、まだ考えるべき距離がある。本書が「夫婦」の不在を問題にするとき、夫婦という二人組を再び唯一の単位として強くする提案より、二人が夫と妻の役割へ隠れず、一緒に生活を作る人として言葉を交わせる関係を求めているのだと読んだが、その関係を支えるものが愛情なのか、制度なのか、周囲に分散した複数のつながりなのかについては、自分の経験を含めて考え続けたい。

## 正しさより先に、関係がある

『「夫婦」不在社会』を読み終えた私には、正しい説明が相手へ届かなかったときに、説明を磨くのか、相手を責めるのか、それとも二人が使っている言葉そのものを見直せるのかという問いが残った。

仕事では、論理の正しさが多くの人を守る場面があり、病院で曖昧な判断を放置すれば患者へ不利益を与えるため、生活の言葉を仕事へ持ち込むときにも、根拠と責任を保たなければならない。相手の反応を見ながら伝え方を変え、自分の論理が届かなかった理由を関係の中で考えることは、正しさを相手へ渡すために必要な技術である。

家庭でも、感情を尊重するという名目で役割や負担を曖昧にすれば、誰か一人が生活を支えることになるので、関係を大切にすることと、分担を言葉にすることを対立させるべきではない。必要なのは、分担を決める論理が、相手の存在価値を測る尺度へ変わっていないかを確かめ、正しい側が話し続け、説明できない側が黙る構図を作らないことだと思う。同時に、正しい側もまた黙っていることを見落とさないほうがよい。説明できる話題の外側では、こちらにも言葉がなく、その沈黙は配慮の形をとることもあれば、関心の欠如として相手に届くこともある。

三宅さんが物語の中から探した夫婦の姿を通して、大学院時代と、仕事と生活を分けずに生きたいという現在の感覚を読み直した。前著を読んだときには、本を読めなかった経験を労働の構造から考え直し、本書を読んだ後には、その構造が二人の関係へ入ったとき、生活の中にどのような沈黙を作るのかが見えるようになった。

次に老子や荘子を読むとき、無為を、自分の正しさで関係を押し切らず、その場にある流れや相手の反応に沿って技術を使うこととして考えてみたい。夫婦について読んだはずの本が、臨床やサーフィンや無為へつながってしまうところに、読書を続ける理由がある。
## この本から続く本

この本を読んで残った問いから、次に読む本を決めている。読んでいる途中のものと、まだ開いていないものが混ざっているので、その別も書いておく。

- **三宅香帆『なぜ働いていると本が読めなくなるのか』(集英社新書、2024年)** — 前著にあたる。この記事の出発点になった、本が読めなくなる生活のほうを扱っている。[Amazon.co.jpで見る](https://www.amazon.co.jp/dp/4087213129)
- **國分功一郎『中動態の世界 意志と責任の考古学』(新潮文庫、2025年)** — その削減は自分の意志で行っていた、と書いたところが、この本を読み始めてから落ち着かなくなった。する側とされる側のどちらにも収まらない言い方が実際にあったらしい、というところまで来ている。まだ読んでいる途中で、結論を持ち出せる段階ではない。[Amazon.co.jpで見る](https://www.amazon.co.jp/dp/4101035423)
- **中島隆博『荘子 鶏となって時を告げよ』(岩波書店、2009年)** — 正しさで関係を押し切らないという最後の問いを持ったまま、原典の前にこの一冊から読んでいる。是非を争う場面が出てくるたびに、家庭での会話のほうを思い出している。読み終えていないので、どう着地するかはまだ書けない。[Amazon.co.jpで見る](https://www.amazon.co.jp/dp/4000282921)
- **近内悠太『世界は贈与でできている』(NewsPicksパブリッシング、2020年)** — 依存先の分散を投資の言葉だけで語る危険について書いたが、交換にならない関係をどう考えるかを、副題にある資本主義のすきまという言葉から辿ってみたい。まだ開いていない。[Amazon.co.jpで見る](https://www.amazon.co.jp/dp/4910063056)
