# なぜ、忙しかった頃の私は本が読めなかったのか

紹介している本は、記事末尾の出版社公式ページとAmazon商品ページから確認できます。現在のAmazonリンクは通常の商品リンクであり、芥川寅之介への紹介料は発生しません。Amazonアソシエイトを有効にした場合は、記事冒頭にその旨を明記します。

大学院に通っていた頃、本が読めなくなったのだが、仕事をしながら研究を進め、課題を提出し、専門職として身につけるべき知識にも遅れまいとしていたのだから、読書に使える時間が減るのは仕方がないと考えていたし、数頁読んでも内容が頭に残らず、買った本だけが棚に増えていく様子を見ても、時間の使い方が下手で、集中力も足りない自分に原因があると思っていた。

仕事と大学院を両立させるために、生活の中からいくつかのものを外した。サーフィンをやめ、運動する時間を減らし、研究や仕事と関係のない本を後回しにしたのだが、その選択には筋が通っているように見えたし、将来のために一定の期間を差し出しているのだと考えれば、窮屈さにも名前をつけずに済んだ。

ところが、三宅香帆さんの『なぜ働いていると本が読めなくなるのか』を読んでから、あの時期を、自分の生活能力が足りなかったという話だけでは説明できなくなった。本書は、会社員になると読書の時間がなくなるという身近な悩みから出発しながら、明治以降の労働と読書の歴史をたどり、働く人が仕事に全身全霊を求められるようになった過程を描いており、読書を個人の趣味として守るための小さな工夫よりも、その趣味を圧迫する働き方の側へ目を向けている。

この本を、働きながら本を読むための方法を教える本として読み始めたが、読み終えたときには、なぜサーフィンまでやめたのかを考えていた。

## 用途を説明できる本だけが残った

大学院時代には、本を手に取るたびに、その本が研究に使えるか、仕事に生かせるか、論文の材料になるかを考えており、どの問いにも答えられない小説や哲学書を開くと、いま読む必要があるのかという疑いがすぐに生じたため、読書を禁じられたわけでもないのに、目の前の課題と関係のない本を自分から閉じていた。

同じことは、サーフィンや運動にも起きていた。海へ行けば半日がなくなり、運動をすれば疲れて研究の能率が落ちるかもしれないので、その時間を課題へ振り向けたほうがよいと考えたのだが、そうやって確保した時間を使い切っても余裕は生まれず、次の課題と、その次に身につけるべき知識が現れた。

生活の時間を、将来の成果へ変換できるかどうかで選別していたのだと思う。眠るのは翌日の能率を保つためであり、運動するなら健康管理という目的が要り、本を読むなら仕事か研究への効果を説明できなければならないという具合に、行為の外側に用途を置き、その用途が行為を許可する仕組みを、自分の中に作っていた。

大学院で学んだ内容にも、そこで出会った人にも価値があり、仕事と研究を両立する時期に何かを減らす判断まで否定したいわけではない。振り返って気になるのは、その時期を区切らず、生活のほぼ全域に同じ判断基準を適用し、何かを楽しむ時間にも将来の成果を要求したため、生活を整える行為と生活そのものを区別できなくなっていたことである。

## 読書が持ち込むノイズ

三宅さんは本書の中で、読書が自分にとって必要な情報だけを受け取る行為ではなく、自分の関心や予想から外れた情報、つまりノイズを含む行為であることを論じている。仕事に追われた人が疲れた夜にスマートフォンを眺めるとき、自分の関心に合わせて選ばれた情報は受け取りやすいが、一冊の本を読み進めるには、すぐには用途の分からない記述や、これまで考えたことのない他人の文脈に付き合わなければならない。

この指摘を読んだとき、本を読む時間より先に、ノイズを受け取る余白を失っていたのではないかと思った。大学院時代にも電車で移動する時間や休日はあったが、頭の中では課題が終わっておらず、目の前の文章が研究とどうつながるかを測り続けていたので、目的から外れた一文に立ち止まり、その一文がどこへ連れていくか分からないまま読み進めることが難しかった。

本は、こちらが設定した課題へ従ってくれるとは限らない。探していた答えとは関係のない一節が残り、読んだ直後には理解できなかった話が、何年か後の経験と結びつくこともあるのだが、当時は、その時間差を待つより、読んだものを早く知識へ変え、説明できる形にまとめることを優先していた。

読書をしていながら、読書がもたらす予定外の作用を避けていたのである。

## 自己投資としての読書

本を読む目的に、知識を得ることや仕事へ生かすことが含まれていても困らないし、臨床や教育に必要な本なら、内容を整理して使える形にしたほうがよい。しかし、すべての読書に同じ態度を持ち込むと、読んだ冊数、得た知識、説明できる要点が読書の成果になり、棚に並ぶ本も、自分の能力を高めるための教材か、まだ活用できていない資産のように見えてくる。

自己投資という言葉は、学ぶことを肯定しやすくする一方で、現在の時間を将来の自分へ貸し出す見方を含んでいる。大学院時代には、いま過ごしている時間を将来の能力へ変えようとし、その変換に参加しない読書や運動を生活から外したのだが、将来の自分はいつになっても現在にはならず、能力を増やした自分には、さらに次の能力が必要になった。

三宅さんが提示する「半身で働く」という考えには、大筋でうなずける。仕事へ全身全霊を差し出さず、仕事とは別の世界からノイズを受け取れる部分を残すことは、本を読むためにも、生活を仕事の付属物にしないためにも必要だと思う。

ただ、自分の生活を振り返ると、仕事と生活を二つに分け、半分ずつ配分すれば解決するとも思えない。仕事、家族、読書、サーフィン、AIを使った制作は互いに影響し合っており、読書で出会った概念を臨床の経験から考え、サーフィンで感じたことを老子や荘子の言葉で読み直すこともあるため、求めているのは整然とした分離より、どれか一つが残りを併合しないための複数の足場なのだろう。

大学院時代には、仕事と研究がほかの足場を取り払い、生産の論理が生活の側へ流れ込んだ。いま確かめたいのは、その向きを逆にして、読書や身体の時間から得たものを仕事へ持ち込みながらも、読書や身体の時間を仕事のための資源に変えきらずに済むかということである。

## サーフィンをやめたことから考える

サーフィンでは、波を自分で作れない。海へ入り、うねりを見て、位置を変え、来た波に合わせて漕ぐため、何もしなければ乗れないが、努力した分だけ望んだ波が来るとも限らず、自分の技術と、自分では決められない条件の両方がそろったときに、一本の波に乗ることができる。

大学院時代、このような時間を役に立たないものとして切り離したわけではなく、研究や仕事へ集中するために一時停止したつもりだったが、いま振り返ると、サーフィンをやめたことで、目的を立て、計画し、努力して成果を得るという型から外れる身体の経験も失っていた。

この経験は、これから老子や荘子を読み、無為について考えるときの足場になると思う。無為を何もしないこととして理解すれば、波を読み、位置を取り、技術を使うサーフィンとは結びつかないが、自分では作れない流れに応じる技術として理解するなら、意志と努力だけでは説明できない行為の形が見えてくる。

本書はサーフィンや無為を論じていないので、この接続は三宅さんの主張ではなく、私が自分の経験を読み直すために作ったものである。それでも、一冊の本を読んだあと、書かれていなかった問題が自分の中に残り、別の本へ向かう理由になるなら、それこそ読書が運び込んだノイズの働きなのかもしれない。

## 本を読めなかった過去を、どう読み直すか

『なぜ働いていると本が読めなくなるのか』を読んでも、大学院時代の忙しさが消えるわけではなく、当時の選択がすべて誤りだったとも思わないが、「生活が下手だった」という説明だけを握り続けなくてよくなった。仕事と研究に役立つことを優先し、その基準を生活の隅々へ広げた結果として、本やサーフィンを受け取る余白がなくなったと考えると、集中力の不足として片づけていた経験を、働き方と価値の測り方の問題として捉え直せる。

同時に、本書を読んで「社会が悪かった」と結論づければ、自分が何を選び、何を恐れ、なぜ成果へ向かう時間に安心したのかを見落とす。構造を知ることは、自分の責任を消すためではなく、自分の意志だと思っていた選択に、労働や成長をめぐる社会の言葉がどれほど入り込んでいたかを調べるために使いたい。

このアカウントでは、三宅香帆さんの本から始めて、ヴェーバーの『プロテスタンティズムの倫理と資本主義の精神』、國分功一郎さんの中動態や暇と退屈をめぐる議論、老子や荘子へ読み進めながら、役に立つこと、成長すること、自分で決めることに支えられた生活の外側に、どのような行為と価値があるのかを考えていく。

読み終えた本から答えを一つ取り出すより、その本によって過去の経験の見え方が変わり、次に読む本が決まっていく過程を書き残したい。大学院時代に閉じた本を、いま別の仕方で開き直すところから、芥川寅之介の読書を始める。

読み終えたあとに残った問いから、次に読む本を決めている。まだ読んでいないものも含むので、内容の紹介ではなく、どこがつながっていそうかだけを書いておく。
