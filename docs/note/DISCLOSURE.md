# 背景をどこまで出すか

臨床の背景を記事にどこまで書くかの方針。判断に迷ったらここを見る。

## 前提となる事実

**深みの源と、特定の源は、ほとんど重なっていない。**

| 情報 | 文章の深みへの寄与 | 特定への寄与 |
|---|---|---|
| 治らない病のリハビリに関わっている | 大 | 小 |
| ALS・脳腫瘍・血液がんという領域 | 大 | 中 |
| 受容の過程、本人と家族の葛藤に立ち会う | 大 | 小 |
| 急性期・大学病院という環境 | 中 | 小 |
| 施設名 | ほぼ無し | 大 |
| 役職・担当科の組み合わせ | ほぼ無し | 大 |
| 特許申請 | 小 | 特大 |

施設名や役職を書いても、文章は良くならない。深みは「治らない人と関わり続けている」という事実のほうから来る。だから両者は切り離せる。

## 書く

- 大学病院・急性期という環境
- 神経難病、脳腫瘍、血液がんのリハビリに関わっていること
- 治る人と治らない人の両方と関わること、受容の過程、本人と家族の葛藤
- 分子生物学的な研究への関心

いずれも**一般形で**書く。「〜という場面がある」「〜することが多い」。

## 書かない

- **施設名・地名**(「大学病院」で足りる)
- **役職**、担当科の具体的な組み合わせ
- **特許**(内容も、申請したことも。下記)
- **治験の中身**(下記)
- **個別の患者・家族のエピソード**

`note_lint.py` が公開範囲を検査する(`identifying`)。マーカー以降のメモには書いてよい。

## 特許 — 書かない(決定済み)

**触れない。** 装置のことも、申請したことも書かない。

特許出願は原則として出願から1年6か月で公開され、**発明者名が公開情報になる**。用途や仕組みを書けば検索から発明者に到達でき、**ペンネームから実名への経路が一本できる**。単独で匿名性を壊すため、他の判断と切り離して守る。

## 治験 — 中身に触れない。語そのものも最小限に

**中身は書かない**(対象、薬剤、試験の内容、結果)。これは決定。

そのうえで、**「治験」という語そのものが絞り込みの材料になる**点は意識する。関われる施設は限られ、リハビリ職が関わるとなるとさらに狭い。中身を書かなくても、語が出た時点で効く。

伝えたいのが「そういうものに携われる環境にいる」という感覚なら、語がなくても届く。

- ✗ 治験に関わることもある
- ○ 臨床のすぐ隣で研究が動いている
- ○ 医師や研究者と一緒に考える場面が多い

`note_lint.py` は禁止ではなく確認として警告する。書くと決めたなら書いてよい。

## 個別事例を書かないための具体的な線

具体名がなくても、当事者には刺さる。担当した患者や家族が読んで「自分のことだ」と認識する事態を避ける。

- 疾患・年齢・家族構成・時期の**組み合わせ**を書かない。1つでも特定の糸口になる
- 複数の経験を一般化した形でしか書かない
- 迷ったら書かない。臨床のエピソードは、本当に必要か毎回問う

施設名を出さないことが、この点でも最も効く単一の対策になっている。

## 収益化との関係

**医療者としての肩書きを、本を薦める根拠にしない。** 現在の記事は経験として書いており、この形を保つ。医療・健康の本を薦めるときは特に慎重に。

## この判断は片方向にしか動かない

後から具体を足すことはできるが、一度出したものは戻せない。迷っている間は狭いほうに置く。

## 未決

- 「一般名のまま」と「診療領域まで出す」のどちらを採るか。**どちらを選んでも上の「書かない」は変わらない**ため、この判断を待たずに運用できる
- 就業規則・広報規程の確認(施設名を出さない方針でも、発信そのものに条件がある場合がある)
- 特許出願が公開段階に入っているかの確認
