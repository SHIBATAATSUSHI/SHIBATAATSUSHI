## 見るところ

数字そのものより、**次に何を書くかが変わるか**で見る。

| 指標 | 何が分かるか |
| --- | --- |
| ビュー | タイトルと流入経路が機能したか |
| スキ率(スキ ÷ ビュー) | 内容が刺さったか。ビューが少なくても高ければ主軸候補 |
| コメント・質問 | 読者が具体的に困っていること。次の記事ネタになる |
| 購入 | 有料化の妥当性 |
| 保存・引用 | 手元に置きたい実用性があったか(8本目の判断材料) |

## 判断の区切り

- **10本公開した時点** — 4本柱(臨床判断 / 若手教育 / 組織運営 / AI活用)のうち、
  反応が良かったものを主軸に決める
- **8本目のチェックリスト公開後** — 保存需要があれば、有料商品を質問集・テンプレート型にする
- **最初の有料記事の後** — 売れ行きを見て、メンバーシップに進むかを決める
