# /self-improve — 修正を資産に変える

「専門家の修正が次のバージョンを良くする」ループを Claude Code で回すためのスキル。修正をその場限りにせず、CLAUDE.md に蓄積して次のセッションに引き継ぐ。

## 手順

1. **修正の特定**: 直近の会話から、ユーザーが訂正した内容・示した好みを抽出する。一過性の指示(このタスク限定のもの)は対象外。
2. **一般化**: その修正を「次回も適用できるルール」に1行で言い換える。
   - 悪い例: 「7月17日のコミットメッセージを直した」
   - 良い例: 「コミットメッセージは日本語で、変更理由を含める」
3. **記録**: CLAUDE.md の「学習ログ」セクションに追記する。既存項目と重複・矛盾するなら統合する。
4. **監査(スリム化)**: 追記のたびに学習ログ全体を見直す:
   - 3項目以上が同じテーマなら1つの原則にまとめて「原則」セクションに昇格させる。
   - もう当てはまらない項目・過剰に細かい指示は削除する。**指示は薄いほど守られる。**
5. **報告**: 何を学習ログに追加・整理したかを1〜2行でユーザーに伝える。

## 注意

- ユーザーの発言の意図が「一般ルール」か「今回だけ」か曖昧なときは、勝手に一般化せず確認する。
- CLAUDE.md 全体が50行を超えたら、追記より先に削るものを探す。
