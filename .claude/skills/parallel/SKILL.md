# /parallel — サブエージェント並列化

独立した仕事を並列のサブエージェントに委譲し、蒸留された結果だけをメインスレッドに戻すためのスキル。

## 使いどころ

- 複数箇所の調査(「AとBとCの仕様を調べて」)
- 性能チューニング・マイグレーション・不安定テストの調査・多段リファクタ
- 「調査」と「実装」と「テスト」が互いに待ち合わせ不要なとき

## 手順

1. **分割**: 依頼を互いに依存しないタスクに分解する。依存があるものは並列化せず順番にやる。
2. **委譲**: Agent ツールで各タスクを起動する。調査だけなら `Explore`、設計なら `Plan`、実装を伴うなら `general-purpose` を使う。1つの Agent 呼び出しには:
   - 目的(何を明らかにする/作るか)
   - 範囲(見るべきファイル・ディレクトリ)
   - 返してほしい形式(結論を◯行で、ファイルパス付きで、など)
   を必ず含める。サブエージェントはこの会話の文脈を持たないので、前提はすべてプロンプトに書く。
3. **統合**: 各エージェントの報告を突き合わせ、矛盾があれば自分で該当箇所を確認して解消する。
4. **報告**: ユーザーにはエージェントの生ログではなく、統合した結論だけを伝える。

## 注意

- 同じファイルを複数のエージェントに同時に編集させない(コンフリクトする)。編集の並列化はファイル単位で分ける。
- 2つ程度の軽い調査なら自分で直列にやったほうが速い。並列化は分割・統合のコストに見合うときだけ。
