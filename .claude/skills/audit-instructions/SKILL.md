# /audit-instructions — 指示の定期監査

モデルは意図に従う能力が上がり続けているので、細かすぎる指示はワークフローを保ったままコンテキストの無駄になる。CLAUDE.md と `.claude/skills/` を定期的に監査して薄く保つ。

## チェックリスト

CLAUDE.md と各 SKILL.md を読み、次に該当するものを列挙する:

1. **重複**: 複数の場所で同じことを言っている(→1箇所に統合)
2. **過剰な規定**: 手順を細かく縛りすぎていて、意図だけ書けば足りる(→意図に書き換え)
3. **死んだ指示**: もう存在しないファイル・ワークフローに言及している(→削除)
4. **一過性の残骸**: 特定のタスク向けだった記述が残っている(→削除)
5. **昇格候補**: 学習ログに溜まった同テーマの項目(→原則に統合)

## 手順

1. 上記チェックリストで問題点を列挙し、それぞれに「統合/書き換え/削除」の提案を付けてユーザーに提示する。
2. 承認されたものを適用する。削除に迷うものは提案に留める。
3. 適用後、削減した行数と残った構成を報告する。
