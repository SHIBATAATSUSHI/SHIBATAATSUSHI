# 競馬予想 較正台帳

競馬の予想を「当たったか」ではなく「較正されているか」で評価し、蓄積するための台帳。

## なぜ作るか

競馬では毎日数千の予測が発行され、正解が数分後に確定し、しかも全部公開されている。
較正を測る条件がこれほど揃っている領域は珍しい。それなのに**答え合わせの台帳が存在しない**。

理由は技術ではなく、買い手がいないこと。主催者が売っている商品は的中精度ではなく分散
そのもので、控除率20〜27.5%は「外れる権利の価格」にあたる。予想家が売っているのは物語で、
評価指標が的中率と回収率という分散の大きい指標だから事後にどうとでも語れる。
較正で測られると困る側しか、この市場にはいない。

だから空白として残っている。ここはその空白を埋める記録である。

**スコープ外**: 的中率、回収率、期待値、馬券の買い方。この台帳は予想を当てるための道具ではなく、
予想を測るための道具である。

## 測定手続き

### 1. 生値を記録する

正規化済みの確率を保存してはいけない。控除率の仮定を後から差し替えられなくなる。
`records/*.json` に保存するのはオッズの生値と、逆数和がどこから来たかだけ。

### 2. 逆数和(オーバーラウンド)を同定する

単勝オッズの逆数和 Σ(1/オッズ) は、正常な市場なら払戻率の逆数になる(単勝80% → 1.25)。

2026/8/1 札幌7R・8Rでは、**紙面の予想オッズの逆数和が両レースとも1.24前後**だった。
これは紙面が控除率を織り込んだ**模擬市場価格**として設計されていることを意味する。
つまり紙面の数字は確率ではない。確率として扱うには正規化が必須。

逆数和の出どころは3種類あり、どれかで使える指標が変わるので必ず明示する。

| basis | 意味 | 正規化 |
|---|---|---|
| `measured` | 全馬のオッズから実測した | 可 |
| `assumed_takeout` | 控除率から仮定した(1/0.8 = 1.25) | 可 |
| `partial_field` | 一部頭数だけの部分和 | **不可** |

部分和での正規化は禁止している。アイビスサマーダッシュ前売りの「上位10頭の逆数和1.154」で
割ると、残りの馬が持つ逆数質量を無視するぶん確率を過大評価する。実プールなら全馬の逆数和は
控除率どおり1.25とみなし、1.154は整合性検査に使う(残り質量0.096 → 18頭立てなら残り8頭の
平均単勝は約83倍で、直線1000mの下位人気として妥当)。

### 3. 正規化してスコアをつける

p_i = (1/オッズ_i) / 逆数和

## 指標の使い分け

| 指標 | 必要な記録 | 用途 |
|---|---|---|
| **log loss** | 1着馬のオッズ+逆数和 | 主力。不完全な記録でも計算できる |
| **Brier**(総和形) | 全馬のオッズ | 外した先の分布まで含めた評価。0〜2、小さいほど良い |
| **entropy** | 全馬のオッズ | 分布の平坦さ。H1を測る道具 |
| **KL divergence** | 全馬のオッズ×2時点 | 2つの分布の隔たり |
| **乖離倍率** | 1着馬のオッズ×2時点 | 事前価格 ÷ 事後価格 |

**不完全な記録を捨てない**のがこの台帳の設計上の要。全馬のオッズが揃うまで何も出ない設計に
すると n が永遠に増えない。1着馬の確率さえ分かれば log loss は出るので、そこを主力に据える。

### 使わない指標

- **的中率・回収率** — 分散が大きすぎて、100レース程度では予想の質と区別がつかない
- **配当額** — 予測精度の指標にならない。7Rの3連単63,060円は派手だが1,320通り中251番人気=
  上位19%であり、組合せ空間の分母が膨らんだことと3連単の払戻率が72.5%と最低であることの
  帰結にすぎない。`payouts` には保存するがスコアには一切使わない

## 反証可能な仮説

### H1 紙面の分布は市場より平坦で、実際の1番人気を系統的に過小評価する ← 本命

逆数和という総量は正しいのに、配分が甘い。7Rは31.2倍→5.5倍、8Rは2.6倍→1.4倍で、
個別の外し方はランダムに見えるのに**方向が一致している**。

各レースで p_紙面(1着) < p_確定(1着) かを数え、符号検定にかける。偏りがなければ半々に
なるはず、が帰無仮説。n=2では2連続同方向でも両側p=0.5にしかならない(道具がそう自己申告する)。
実質的な最小サンプルは n=5(全同方向でp=0.0625)。

**これが本命である理由**: 恒常性が確認できれば、それは予想家の損失関数を測ったことになる。
二乗誤差を最小化しているなら分布は市場に近づくはず。平坦に外れ続けるなら、彼らが最適化して
いるのは的中確率ではなく「穴を当てたときの名声」だという証拠になる。
技術の話がインセンティブの測定に変わる、そこが面白い。

### H2 乖離倍率はクラスの情報厚みで決まる

3歳未勝利(キャリア1〜3戦)で5.67倍、1勝クラスで1.86倍。情報層が厚いほど縮む。
共変量は `career_starts`(馬番→キャリア戦数)に入れる。

### H3 同一市場内20時間の情報流入は、紙面→確定の乖離より小さい

紙面と確定の差の主因は、予想の巧拙(不可約な分散)ではなく**時差**だという読みの検証。
7Rの決着は市場の事前分布から見て上位2〜3割の平凡な位置にあり、「予測困難だった」のではなく
「紙面が遅れていた」。ならば同一市場内の20時間で入る情報は、それより少ないはず。

## 記録手順

1レースにつき5時点を刻む。時刻(`captured_at`)は必ず埋める——これが測定の基点になる。

| 情報源 | タイミング | 狙い |
|---|---|---|
| `紙面` | 前日 | 印刷で固定された予想 |
| `前売り` | 前日発売開始後 | 市場の初期値 |
| `当日午前` | 当日朝 | |
| `締切60分前` | | |
| `締切5分前` | | プロの資金が入る帯。流入曲線の形はここで決まる |
| `確定` | レース後 | 事後の基準 |

可能なら**全馬のオッズ表を撮る**。全馬揃った時点で Brier・エントロピー・KLが解禁される。

### 欠測を消さない

事前価格を撮り損ねたレースは `status: "pending"` で残し、結果だけを後から足さない。
撮れたレースだけを母集団にすると選択バイアスが入る——印象に残ったレースほど記録される、
という偏りは較正の測定を丸ごと無効にする。9R釧路湿原特別がその例。

## 使い方

```bash
python3 analysis/keiba/report.py                          # スコア表と仮説検定
python3 -m unittest discover -s analysis/keiba/tests -v   # 指標の定義の関門
```

## 構成

```
schema.py       Quote / Result / Race。生値のみ保存、正規化は派生値
calibration.py  log loss / Brier / entropy / KL / 符号検定(標準ライブラリのみ)
report.py       記録を読んでスコア表とH1・H2を出力
records/*.json  1ファイル1レース
tests/          指標の定義を固定する検証
```
